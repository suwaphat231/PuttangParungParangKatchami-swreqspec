1. เงื่อนไขและเอกสารเบื้องต้นในการขอ Labboy?
- ประเภทรายวิชา: รายวิชาที่ขอ Labboy ได้ต้องเป็นวิชาปฏิบัติการเท่านั้น โดยสังเกตจาก
รหัสหน่วยกิตที่มีชั่วโมงปฏิบัติการระบุไว้
- เอกสารที่อาจารย์ต้องส่ง:
1.1แบบฟอร์มแจ้งรายชื่อ Labboy ประจำรายวิชา
1.2ตารางการปฏิบัติงานตลอดทั้งเทอม
1.3 หลักฐานการยืนยันตัวตน: ใช้ภาพหน้าจอจากระบบที่แสดงชื่อและรหัสนิสิต เพื่อยืนยันข้อมูล
และป้องกันความผิดพลาดในการระบุชื่อและคำนำหน้าชื่อ
2. การจัดทำและเสนออนุมัติเอกสาร
- การเตรียมเอกสาร: เจ้าหน้าที่จัดทำบันทึกขออนุมัติ ตารางปฏิบัติงาน ใบลงเวลา
รายงานผล และหลักฐานการจ่ายค่าตอบแทนรายเดือน
- ขั้นตอนการอนุมัติ: เจ้าหน้าที่ → หัวหน้าภาควิชา → งานคลังและพัสดุ →
เลขานุการคณะ → คณบดีคณะวิทยาศาสตร์

1.2 User stories/Use Cases
User Stories
US-01: ขอและคัดเลือก Lab Boy
As a อาจารย์ผู้สอน
I want สามารถส่งคำขอและจัดทำรายชื่อ Lab Boy พร้อมตารางปฏิบัติงาน
So that สามารถจัดสรร Lab Boy ให้กับรายวิชาได้อย่างเป็นระบบ
Acceptance Criteria
- ระบุรายวิชาและข้อมูล Lab Boy
- แนบหลักฐานสถานภาพนักศึกษา
- กำหนดวันและเวลาปฏิบัติงาน
- บันทึกและส่งคำขอได้
US-02: ตรวจสอบและอนุมัติคำขอ
As a เจ้าหน้าที่ภาควิชา/หัวหน้าภาควิชา
I want สามารถตรวจสอบข้อมูลและอนุมัติคำขอ Lab Boy
So that การขอ Lab Boy เป็นไปตามระเบียบและข้อมูลถูกต้อง
Acceptance Criteria
- ตรวจสอบประเภทรายวิชาว่าสามารถขอ Lab Boy ได้
- ตรวจสอบรายชื่อและสถานภาพนักศึกษา
- ตรวจสอบตารางปฏิบัติงาน
- อนุมัติหรือส่งกลับเพื่อแก้ไขได้
- สามารถติดตามสถานะการอนุมัติได้
US-03: ลงเวลาและบันทึกการปฏิบัติงาน
As a Lab Boy
I want สามารถลงเวลาเข้า-ออกและบันทึกการปฏิบัติงาน

8
So that มีหลักฐานยืนยันการทำงานสำหรับการเบิกจ่าย
Acceptance Criteria
- บันทึกเวลาเข้าและออก
- ระบบคำนวณชั่วโมงทำงาน
- สามารถตรวจสอบการมาปฏิบัติงานจริงเทียบกับตารางได้
- มีข้อมูลสำหรับจัดทำใบลงเวลา
US-04: ตรวจสอบชั่วโมงและการเบิกจ่าย
As a เจ้าหน้าที่ภาควิชา
I want สามารถตรวจสอบชั่วโมงทำงานและเอกสารประกอบการเบิกจ่าย
So that สามารถเบิกจ่ายค่าตอบแทนได้อย่างถูกต้องตามระเบียบ
Acceptance Criteria
- คำนวณชั่วโมงเป็นหน่วย 60 นาที
- ตรวจสอบวัน เวลา และลายเซ็น
- ตรวจสอบจำนวนชั่วโมงที่สามารถเบิกจ่ายได้
- จัดทำข้อมูลสำหรับเอกสารเบิกจ่าย
US-05: ติดตามสถานะและเอกสาร
As a อาจารย์/เจ้าหน้าที่
I want สามารถดูสถานะคำขอและเอกสารในแต่ละขั้นตอน

Acceptance Criteria
- แสดงสถานะ เช่น รอตรวจสอบ / รออนุมัติ / อนุมัติ / ส่งเบิกจ่าย
- แสดงผู้รับผิดชอบในแต่ละขั้นตอน
- สามารถดูประวัติการดำเนินการได้

1.3.2.4 ข้อจำกัด (Constraints)
หัวข้อนี้รวบรวมข้อจำกัดและเงื่อนไขของระบบ LAB BOY จาก Use Case Specification เพื่อ
กำหนดขอบเขตการใช้งานและการทำงานของระบบ
UC-01 สมัครเป็น Lab Boy
ต้องเข้าสู่ระบบและมีประกาศรับสมัครที่อยู่ในช่วงเวลาเปิดรับสมัคร
•
ข้อมูลที่จำเป็นจากบัญชีผู้ใช้และเอกสารแนบตามรายการในประกาศรับสมัครต้องครบก่อน
•
ยืนยัน
ห้ามสมัครซ้ำในประกาศเดียวกัน และหากจำนวนผู้สมัครเต็มให้รับตามลำดับเวลาที่ยืนยัน
•
สำเร็จ
UC-02 ดูประกาศรับสมัคร
ประกาศที่หมดเขตต้องไม่แสดงเป็นรายการที่สมัครได้
•
ข้อมูลประกาศต้องมาจากเจ้าหน้าที่หรืออาจารย์ที่เผยแพร่
•
UC-03 ดูสถานะการสมัคร
ผู้ใช้ต้องเข้าสู่ระบบและดูได้เฉพาะใบสมัครของตนเอง
•
สถานะต้องอ้างอิงข้อมูลล่าสุด โดยเรียงรายการตามเวลาที่อัปเดตล่าสุดและกรองตาม
•
ประกาศได้
UC-04 เข้าสู่ระบบ
ต้องมีบัญชีที่ได้รับอนุญาตและยืนยันตัวตนผ่าน SSO ของสถาบัน
•
อนุญาตเฉพาะรหัสนักศึกษา รหัสบุคลากร หรืออีเมลมหาวิทยาลัย และต้องไม่เปิดเผย

รหัสผ่านหรือข้อมูลยืนยันตัวตน
