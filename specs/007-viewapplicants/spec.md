# Feature: ดูรายชื่อผู้สมัคร
Spec ID: SPEC-07-07- | Source: Use Case Diagram UC-07 | Use case: UC-07
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-19

## Goal
อาจารย์สามารถดูรายชื่อและข้อมูลที่จำเป็นของผู้สมัครในรอบรับสมัครที่ตนมีสิทธิ์รับผิดชอบเท่านั้น

## Scope
### In scope
- ค้นหารอบรับสมัครที่อาจารย์มีสิทธิ์
- แสดงรายชื่อผู้สมัครในรอบที่มีสิทธิ์
- ค้นหา/กรองผู้สมัครตามเงื่อนไขที่เกี่ยวข้อง
- ดูรายละเอียดใบสมัครและข้อมูลที่มีสิทธิ์เข้าถึงตามบทบาท
### Out of scope
- คัดเลือกผู้สมัคร (UC-08)
- ตรวจสอบเอกสารและอนุมัติ (UC-10)

## Constraints
- ระบบต้องแสดงข้อมูลเฉพาะในรอบ/รายวิชาที่อาจารย์มีสิทธิ์
- ข้อมูลส่วนบุคคลต้องถูกจำกัดตามบทบาทและนโยบายการเข้าถึงข้อมูล
- หากอาจารย์ไม่มีสิทธิ์ในรอบใด ระบบต้องปฏิเสธการเข้าถึงการดูข้อมูลของรอบนั้น

## Requirements
- FR-APP-01 ระบบต้องแสดงรายชื่อผู้สมัครเฉพาะในรอบรับสมัครที่อาจารย์มีสิทธิ์    <- UC-07 requirement 1
- FR-APP-02 ระบบต้องค้นหาและกรองรายชื่อผู้สมัครได้ตามข้อมูลที่เกี่ยวข้อง เช่น ชื่อ รหัสนักศึกษา รอบรับสมัคร และสถานะ    <- UC-07 requirement 2
- FR-APP-03 ระบบต้องปฏิเสธการเข้าถึงข้อมูลเมื่ออาจารย์ไม่มีสิทธิ์ในรอบรับสมัครนั้น    <- UC-07 requirement 3

## Quality Requirements
- NFR-SEC-01 จำกัดการเข้าถึงข้อมูลผู้สมัครตามบทบาทและสิทธิ์ของผู้ใช้งาน
- NFR-PERF-01 ระบบค้นหาและกรองรายชื่อผู้สมัครควรตอบสนองภายในเวลาที่กำหนด

## Acceptance Criteria
- [ ] AC-APP-01 (FR-APP-01)
      Given มีผู้สมัครในรอบรับสมัครที่อาจารย์รับผิดชอบ
            When  เปิดรอบรับสมัคร
            Then  ระบบแสดงรายชื่อผู้สมัครที่เกี่ยวข้องเท่านั้น
- [ ] AC-APP-02 (FR-APP-02)
      Given มีผู้สมัครหลายรายในรอบเดียวกัน
            When  ผู้ใช้ค้นหา/กรองตามชื่อ รหัสนักศึกษา รอบรับสมัคร หรือสถานะ
            Then  ระบบแสดงผลลัพธ์ที่ตรงตามเงื่อนไขที่ค้นหา
- [ ] AC-APP-03 (FR-APP-03)
      Given อาจารย์ไม่มีสิทธิ์ในรอบรับสมัครนั้น
            When  พยายามเปิดดูข้อมูลของรอบดังกล่าว
            Then  ระบบปฏิเสธการเข้าถึงและไม่แสดงรายละเอียดใด ๆ ของผู้สมัคร

## Assumptions & Open Questions
- ASM-01 ข้อมูลผู้สมัครผ่านการบันทึกจาก UC-01
- Q-01 ข้อมูลใดบ้างที่อาจารย์มีสิทธิ์ดูได้จริง เช่น ชื่อ รหัสนักศึกษา เอกสารประกอบ หรือข้อมูลติดต่อ -> ต้องยืนยันตามนโยบายและสิทธิ์ของข้อมูล
