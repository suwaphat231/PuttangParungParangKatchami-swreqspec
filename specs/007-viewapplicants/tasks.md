# Tasks: ดูรายชื่อผู้สมัคร

Feature: ดูรายชื่อผู้สมัคร | Spec ID: SPEC-07-07- | อ้างอิง: plan.md | วันที่: 2569-11-11

สรุป: มี 3 เฟส 4 task, มี 1 task ที่รอ Open Question และเฟสแรกเป็น prototype ที่อาจารย์เปิดดูรายชื่อในรอบที่มีสิทธิ์ได้จริง

## เฟส 1: ดูรายชื่อผู้สมัครในรอบที่มีสิทธิ์ (AC-APP-01)

### T-01 สร้างหน้าจอแสดงรายชื่อผู้สมัครตามสิทธิ์
- รองรับ: FR-APP-01, NFR-SEC-01, Constraint: ระบบต้องแสดงข้อมูลเฉพาะในรอบ/รายวิชาที่อาจารย์มีสิทธิ์
- ตรวจด้วย: AC-APP-01
- ไฟล์ที่แตะ: `frontend/src/pages/ViewApplicantsPage.jsx`, `frontend/src/pages/ViewApplicantsPage.test.jsx`, `frontend/src/App.jsx`
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: `test_AC_APP_01` ผ่านและหน้าจอแสดงเฉพาะรายชื่อผู้สมัครของรอบที่อาจารย์รับผิดชอบ
- สถานะ: เสร็จ รอทีมตรวจ

#### จุดตรวจเฟส 1
- test ที่ต้องผ่านทั้งหมด: `test_AC_APP_01`
- เปิดระบบ: `cd frontend && npm run dev`
- คนลองเองตาม AC-APP-01:
  Given มีผู้สมัครในรอบที่อาจารย์รับผิดชอบ
  When เปิดหน้ารายชื่อผู้สมัครและเลือกรอบที่มีสิทธิ์
  Then เห็นเฉพาะรายชื่อผู้สมัครของรอบนั้น
- ยังขาด: ขอบเขตข้อมูลส่วนบุคคลที่อาจารย์มีสิทธิ์เห็นตาม Q-01

## เฟส 2: ค้นหาและกรองรายชื่อผู้สมัคร (AC-APP-02)

### T-02 เพิ่มการค้นหาและกรองรายชื่อ
- รองรับ: FR-APP-02, NFR-PERF-01
- ตรวจด้วย: AC-APP-02
- ไฟล์ที่แตะ: `frontend/src/pages/ViewApplicantsPage.jsx`, `frontend/src/pages/ViewApplicantsPage.test.jsx`
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: `test_AC_APP_02` ผ่านและผลลัพธ์ตรงกับชื่อ รหัสนักศึกษา รอบรับสมัคร หรือสถานะที่กรอง
- สถานะ: พร้อมทำ

#### จุดตรวจเฟส 2
- test ที่ต้องผ่านทั้งหมด: `test_AC_APP_01`, `test_AC_APP_02`
- เปิดระบบ: `cd frontend && npm run dev`
- คนลองเองตาม AC-APP-02:
  Given มีผู้สมัครหลายรายในรอบเดียวกัน
  When ค้นหาหรือกรองตามชื่อ รหัสนักศึกษา รอบรับสมัคร หรือสถานะ
  Then เห็นเฉพาะผลลัพธ์ที่ตรงตามเงื่อนไข
- ยังขาด: ขอบเขตข้อมูลส่วนบุคคลที่อาจารย์มีสิทธิ์เห็นตาม Q-01

## เฟส 3: ปฏิเสธการเข้าถึงรอบที่ไม่มีสิทธิ์ (AC-APP-03)

### T-03 เพิ่มสถานะปฏิเสธการเข้าถึงข้อมูลนอกสิทธิ์
- รองรับ: FR-APP-03, NFR-SEC-01, Constraint: หากอาจารย์ไม่มีสิทธิ์ในรอบใด ระบบต้องปฏิเสธการเข้าถึงการดูข้อมูลของรอบนั้น
- ตรวจด้วย: AC-APP-03
- ไฟล์ที่แตะ: `frontend/src/pages/ViewApplicantsPage.jsx`, `frontend/src/pages/ViewApplicantsPage.test.jsx`
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: `test_AC_APP_03` ผ่านและรอบที่ไม่มีสิทธิ์ไม่แสดงรายละเอียดผู้สมัคร
- สถานะ: พร้อมทำ

#### จุดตรวจเฟส 3
- test ที่ต้องผ่านทั้งหมด: `test_AC_APP_01`, `test_AC_APP_02`, `test_AC_APP_03`
- เปิดระบบ: `cd frontend && npm run dev`
- คนลองเองตาม AC-APP-03:
  Given อาจารย์ไม่มีสิทธิ์ในรอบรับสมัคร
  When พยายามเปิดดูข้อมูลของรอบนั้น
  Then ระบบปฏิเสธการเข้าถึงและไม่แสดงรายละเอียดผู้สมัคร
- ยังขาด: ขอบเขตข้อมูลส่วนบุคคลที่อาจารย์มีสิทธิ์เห็นตาม Q-01
