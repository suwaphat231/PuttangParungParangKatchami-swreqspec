## เฟส 1: ดูรายชื่อผู้สมัครในรอบที่มีสิทธิ์ (AC-APP-01)

### T-01 แสดงรายชื่อผู้สมัครตามสิทธิ์ของอาจารย์
- รองรับ: FR-APP-01, NFR-SEC-01, Constraint: ระบบต้องแสดงข้อมูลเฉพาะในรอบ/รายวิชาที่อาจารย์มีสิทธิ์
- ตรวจด้วย: AC-APP-01
- ไฟล์ที่แตะ: ยังไม่ระบุใน plan.md; ต้องกำหนดในแผนทางเทคนิคก่อนเริ่ม implement
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: เมื่ออาจารย์เปิดรอบที่รับผิดชอบ ระบบแสดงเฉพาะรายชื่อผู้สมัครในรอบนั้น
- สถานะ: พร้อมทำ

#### จุดตรวจเฟส 1
- test ที่ต้องผ่านทั้งหมด: `test_AC_APP_01` และ test ของเฟสก่อนหน้าต้องยังผ่าน
- เปิดระบบ: ยังไม่ระบุคำสั่งเปิดระบบใน plan.md
- คนลองเองตาม AC-APP-01:
  Given มีผู้สมัครในรอบที่อาจารย์รับผิดชอบ
  When เปิดรอบรับสมัคร
  Then ระบบแสดงเฉพาะรายชื่อผู้สมัครที่เกี่ยวข้อง
- ยังขาด: ขอบเขตข้อมูลส่วนบุคคลที่อาจารย์มีสิทธิ์เห็นตาม Q-01

## เฟส 2: ค้นหาและกรองรายชื่อผู้สมัคร (AC-APP-02)

- ตรวจด้วย: AC-APP-02
- ไฟล์ที่แตะ: ยังไม่ระบุใน plan.md; ต้องกำหนดในแผนทางเทคนิคก่อนเริ่ม implement
