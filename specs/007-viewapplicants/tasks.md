งานเรียงจากการกำหนดขอบเขตข้อมูลและสิทธิ์ ไปยังการค้นหา หน้าจอ และการเชื่อมต่อจริง

### T-01 ตรวจสอบสิทธิ์และจำกัดข้อมูลผู้สมัคร
- รองรับ: FR-APP-01, FR-APP-03, NFR-SEC-01
- ตรวจด้วย: AC-APP-01, AC-APP-03, AC-APP-04
- ไฟล์ที่แตะ: `backend/` ตามโครงที่มีอยู่
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: ผู้มีสิทธิ์เห็นเฉพาะรอบที่รับผิดชอบและข้อมูล 4 รายการที่กำหนด ส่วนผู้ไม่มีสิทธิ์ได้ 403 โดยไม่เห็นรายละเอียด
- สถานะ: พร้อมทำ

### T-02 ค้นหาและกรองรายชื่อผู้สมัคร
- รองรับ: FR-APP-02
- ตรวจด้วย: AC-APP-02
- ไฟล์ที่แตะ: `backend/` ตามโครงที่มีอยู่
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: ระบบค้นหาและกรองตามชื่อ รหัสนักศึกษา รอบรับสมัคร หรือสถานะ แล้วคืนเฉพาะผลลัพธ์ที่ตรงเงื่อนไข
- สถานะ: พร้อมทำ

### T-03 ทำหน้าจอรายชื่อและตัวกรองด้วย API จำลอง
- รองรับ: FR-APP-01, FR-APP-02, NFR-SEC-01
- ตรวจด้วย: AC-APP-01, AC-APP-02, AC-APP-04
- ไฟล์ที่แตะ: `frontend/src/App.jsx`, `frontend/src/api/client.js`, `frontend/src/index.css`
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: หน้าจอจำลองแสดงรายชื่อเฉพาะข้อมูลที่อนุญาตและกรองตามเงื่อนไขได้
- สถานะ: พร้อมทำ

### T-04 แสดงการปฏิเสธสิทธิ์ในหน้าจอ
- รองรับ: FR-APP-03, NFR-SEC-01
- ตรวจด้วย: AC-APP-03
- ไฟล์ที่แตะ: `frontend/src/App.jsx`, `frontend/src/api/client.js`, `frontend/src/index.css`
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: หน้าจอจำลอง response 403 แล้วไม่แสดงรายละเอียดผู้สมัคร
- สถานะ: พร้อมทำ

### T-05 เชื่อมหน้าจอกับ API จริงและตรวจเวลาตอบสนอง
- รองรับ: FR-APP-01, FR-APP-02, FR-APP-03, NFR-SEC-01, NFR-PERF-01
- ตรวจด้วย: AC-APP-01, AC-APP-02, AC-APP-03, AC-APP-05
- ไฟล์ที่แตะ: `backend/`, `frontend/src/api/client.js`, `frontend/src/App.jsx`
- ต้องทำหลัง: T-01, T-02, T-03, T-04
- เสร็จเมื่อ: หน้าจอใช้ API จริง แสดงผล/403 ถูกต้อง และคำขอค้นหาหรือกรองตอบสนองภายใน 2 วินาที
- สถานะ: พร้อมทำ
