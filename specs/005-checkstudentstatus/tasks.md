งานเรียงจากการกำหนดสัญญาข้อมูลและการตรวจสอบผล ไปยังหน้าจอและการเชื่อมต่อจริง

### T-01 กำหนดสัญญาการตรวจสอบสถานะ
- รองรับ: FR-REG-01, FR-REG-02, ASM-01, Q-01
- ตรวจด้วย: AC-REG-01
- ไฟล์ที่แตะ: `backend/` และ `frontend/src/api/client.js` ตามโครงที่มีอยู่
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: มีสัญญาการส่งรหัสนักศึกษา ชื่อ และอีเมลมหาวิทยาลัย รวมถึงรูปแบบสถานะที่รับกลับ ซึ่งทีมตรวจสอบได้
- สถานะ: รอ Q-01

### T-02 ทำตัวแปลผลสถานะผ่าน
- รองรับ: FR-REG-02
- ตรวจด้วย: AC-REG-02
- ไฟล์ที่แตะ: `backend/` ตามโครงที่มีอยู่
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: ผลสถานะ “ปกติ” ถูกแปลเป็นผลตรวจสอบผ่าน และสถานะอื่นไม่ถูกแปลเป็นผ่าน
- สถานะ: พร้อมทำ

### T-03 ทำการปฏิเสธแบบ fail-closed เมื่อการตรวจสอบผิดพลาด
- รองรับ: FR-REG-03, NFR-REL-01
- ตรวจด้วย: AC-REG-03, AC-REG-04
- ไฟล์ที่แตะ: `backend/` ตามโครงที่มีอยู่
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: กรณีระบบทะเบียนไม่ตอบสนอง ไม่พบข้อมูล ข้อมูลไม่ครบ หรือสถานะผิดปกติ ไม่ก่อให้เกิดผลผ่าน และกรณีที่กำหนดตอบ 404 ได้
- สถานะ: พร้อมทำ

### T-04 บันทึกผลการตรวจสอบที่จำเป็น
- รองรับ: FR-REG-04, ข้อจำกัดเรื่องการใช้ข้อมูลส่วนบุคคลเท่าที่จำเป็น, Q-02
- ตรวจด้วย: AC-REG-05
- ไฟล์ที่แตะ: `backend/` ตามโครงที่มีอยู่
- ต้องทำหลัง: T-02
- เสร็จเมื่อ: ระบบบันทึกรหัสนักศึกษา ชื่อนักศึกษา และสถานะ โดยไม่เก็บข้อมูลเกินความจำเป็นตามที่ทีมยืนยัน
- สถานะ: รอ Q-02

### T-05 ทำหน้าจอแสดงผลและรีเฟรชการตรวจสอบ
- รองรับ: FR-REG-03, NFR-UX-01
- ตรวจด้วย: AC-REG-04
- ไฟล์ที่แตะ: `frontend/src/App.jsx`, `frontend/src/api/client.js`, `frontend/src/index.css`
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: หน้าจอจำลองการเรียก API แสดงข้อผิดพลาด 404 และมีปุ่มรีเฟรชเพื่อลองตรวจสอบใหม่ได้
- สถานะ: พร้อมทำ

### T-06 ป้องกันการสมัครเมื่อข้อมูลไม่ครบ
- รองรับ: FR-REG-03
- ตรวจด้วย: AC-REG-06
- ไฟล์ที่แตะ: `frontend/src/App.jsx`, `frontend/src/__tests__/setup.test.jsx`
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: หน้าจอไม่แสดงข้อมูลการสมัครและปุ่มสมัครไม่สามารถใช้งานได้เมื่อข้อมูลไม่ครบ
- สถานะ: พร้อมทำ

### T-07 เชื่อมต่อหน้าจอและระบบตรวจสอบกับ API จริง
- รองรับ: FR-REG-01, FR-REG-02, FR-REG-03, FR-REG-04, NFR-SEC-01, Q-03
- ตรวจด้วย: AC-REG-01, AC-REG-02, AC-REG-03, AC-REG-05
- ไฟล์ที่แตะ: `backend/`, `frontend/src/api/client.js`, `frontend/src/App.jsx`
- ต้องทำหลัง: T-02, T-03, T-04, T-05, T-06

- สถานะ: รอ Q-03
