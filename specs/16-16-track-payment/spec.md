# Feature: ติดตามและตรวจสอบการจ่ายเงิน
Spec ID: SPEC-16-16- | Source: Use Case Diagram UC-16 | Use case: UC-16
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-19

## Goal
เจ้าหน้าที่สามารถติดตามและตรวจสอบสถานะการจ่ายเงินของ Lab Boy จากข้อมูลการปฏิบัติงานและข้อมูลล่าสุดจากระบบการเงิน เพื่อระบุรายการที่ยังไม่ได้รับชำระหรือมีความผิดปกติ

## Scope
### In scope
- ค้นหาผู้ปฏิบัติงานหรือรายการที่เกี่ยวข้อง
- ดูยอด/รายการจ่ายเงินที่เกี่ยวข้อง
- ดึงและแสดงสถานะการจ่ายเงินล่าสุดจากระบบการเงิน
- ระบุรายการที่ยังไม่จ่ายหรือมีความผิดปกติให้ดำเนินการต่อ
- กรองข้อมูลตามสิทธิ์และบทบาทของผู้ใช้งาน
### Out of scope
- ดำเนินการจ่ายเงินเอง (UC-21)

## Constraints
- ข้อมูลการเงินเข้าถึงได้เฉพาะผู้มีสิทธิ์ตามบทบาทและสิทธิ์ของผู้ใช้งาน
- หน้าติดตามและตรวจสอบเป็นแบบ Read-only ไม่อนุญาตให้แก้ไขข้อมูลต้นทางหรือเปลี่ยนสถานะการจ่ายเงินผ่านหน้าจอนี้
- ระบบการเงินเป็นแหล่งข้อมูลสถานะการจ่ายเงินที่ถูกต้องและเป็นแหล่งข้อมูลหลัก
- รายการที่ยังไม่จ่ายหรือผิดปกติต้องถูกทำเครื่องหมายชัดเจนเพื่อให้เจ้าหน้าที่ดำเนินการต่อ

## Requirements
- FR-PAY-01 ระบบต้องแสดงรายการจ่ายเงินที่เกี่ยวข้องกับผู้ปฏิบัติงานที่เลือกได้ตามตัวกรองที่กำหนด    <- UC-16 requirement 1
- FR-PAY-02 ระบบต้องแสดงสถานะล่าสุดของรายการจากระบบการเงินให้เจ้าหน้าที่เห็นอย่างถูกต้อง    <- UC-16 requirement 2
- FR-PAY-03 ระบบต้องระบุรายการที่ยังไม่ได้จ่ายหรือมีความผิดปกติ เพื่อให้เจ้าหน้าที่ดำเนินการต่อ    <- UC-16 requirement 3
- FR-PAY-04 ระบบต้องจำกัดการเข้าถึงข้อมูลการเงินตามบทบาทและสิทธิ์ของผู้ใช้งาน    <- NFR-SEC-01
- FR-PAY-05 ระบบต้องบันทึกการเข้าถึงและเรียกดูข้อมูลการเงินเพื่อการตรวจสอบย้อนหลัง    <- NFR-AUD-01

## Quality Requirements
- NFR-SEC-01 จำกัดสิทธิ์การเข้าถึงข้อมูลการเงินตามบทบาทและสิทธิ์ของผู้ใช้งาน
- NFR-AUD-01 บันทึกการเข้าถึงและเรียกดูข้อมูลการเงินเพื่อการตรวจสอบย้อนหลัง

## Acceptance Criteria
- [ ] AC-PAY-01 (FR-PAY-02)
      Given ระบบการเงินมีข้อมูลสถานะล่าสุดสำหรับรายการ
            When  เจ้าหน้าที่เปิดหน้า tracking หรือเลือกรายการที่เกี่ยวข้อง
            Then  ระบบแสดงสถานะล่าสุดของรายการจากระบบการเงิน
- [ ] AC-PAY-02 (FR-PAY-03)
      Given มีรายการที่ยังไม่จ่ายหรือผิดปกติ
            When  เจ้าหน้าที่เปิดหน้าติดตาม
            Then  รายการดังกล่าวถูกทำเครื่องหมายเพื่อให้เจ้าหน้าที่ดำเนินการต่อ
- [ ] AC-PAY-03 (FR-PAY-01)
      Given เจ้าหน้าที่ค้นหาผู้ปฏิบัติงานหรือรายการ
            When  ระบบแสดงหน้าติดตาม
            Then  รายการที่เกี่ยวข้องกับการจ่ายเงินทั้งหมดจะแสดงให้เห็นตามตัวกรองที่เลือก
- [ ] AC-PAY-04 (FR-PAY-04)
      Given ผู้ใช้งานมีบทบาทต่างกัน
            When  เข้าถึงหน้าติดตามและตรวจสอบการจ่ายเงิน
            Then  ระบบแสดงข้อมูลตามสิทธิ์และขอบเขตของบทบาทที่อนุญาตเท่านั้น
- [ ] AC-PAY-05 (FR-PAY-05)
      Given มีการเข้าถึงหรือเรียกดูข้อมูลการเงิน
            When  เจ้าหน้าที่เปิดหรือค้นหารายการ
            Then  ระบบบันทึกการเข้าถึงและเรียกดูข้อมูลการเงินไว้ใน Audit Log
