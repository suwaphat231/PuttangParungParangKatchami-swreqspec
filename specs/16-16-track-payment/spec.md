# Feature: ติดตามและตรวจสอบการจ่ายเงิน
Spec ID: SPEC-16-16- | Source: Use Case Diagram UC-16 | Use case: UC-16
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-19

## Goal
เจ้าหน้าที่สามารถติดตามสถานะการจ่ายเงินของ Lab Boy ตามข้อมูลการปฏิบัติงานและข้อมูลล่าสุดจากระบบการเงิน เพื่อระบุรายการที่ยังไม่ได้รับชำระหรือผิดปกติ

## Scope
### In scope
- ค้นหาผู้ปฏิบัติงานหรือรายการที่เกี่ยวข้อง
- ดูยอด/รายการจ่ายเงินที่เกี่ยวข้อง
- ดึงและแสดงสถานะการจ่ายเงินจากระบบการเงิน
- ระบุรายการที่ยังไม่จ่าย/ผิดปกติให้ดำเนินการต่อ
### Out of scope
- ดำเนินการจ่ายเงินเอง (UC-21)

## Constraints
- ข้อมูลการเงินเข้าถึงได้เฉพาะผู้มีสิทธิ์
- ต้องไม่แก้ไขข้อมูลต้นทางจากหน้าติดตาม
- ต้องแสดงข้อมูลจากระบบการเงินในรูปแบบที่อ่านได้และไม่ทำให้ข้อมูลต้นทางเปลี่ยนแปลง

## Requirements
- FR-PAY-01 ระบบต้องแสดงรายการจ่ายเงินที่เกี่ยวข้องกับผู้ปฏิบัติงานที่เลือก    <- UC-16 requirement 1
- FR-PAY-02 ระบบต้องแสดงสถานะล่าสุดของรายการจากระบบการเงิน    <- UC-16 requirement 2
- FR-PAY-03 ระบบต้องระบุรายการที่ยังไม่ได้จ่ายหรือมีความผิดปกติ เพื่อให้เจ้าหน้าที่ดำเนินการต่อ    <- UC-16 requirement 3

## Quality Requirements
- NFR-SEC-01 จำกัดสิทธิ์การเข้าถึงข้อมูลการเงินตามบทบาทและสิทธิ์ของผู้ใช้งาน
- NFR-AUD-01 บันทึกการเข้าถึงและเรียกดูข้อมูลการเงินเพื่อการตรวจสอบย้อนหลัง

## Acceptance Criteria
- [ ] AC-PAY-01 (FR-PAY-02)
      Given ระบบการเงินมีข้อมูลสถานะล่าสุดสำหรับรายการ
            When  เจ้าหน้าที่เปิดหน้า tracking หรือเลือกรายการที่เกี่ยวข้อง
            Then  ระบบแสดงสถานะล่าสุดของรายการจากระบบการเงิน
- [ ] AC-PAY-02 (FR-PAY-03)
      Given มีรายการที่ยังไม่จ่ายหรือผิดปกติ
            When  เจ้าหน้าที่เปิดหน้าติดตาม
            Then  รายการดังกล่าวถูกทำเครื่องหมายเพื่อให้เจ้าหน้าที่ดำเนินการต่อ
- [ ] AC-PAY-03 (FR-PAY-01)
      Given เจ้าหน้าที่ค้นหาผู้ปฏิบัติงานหรือรายการ
            When  ระบบแสดงหน้าติดตาม
            Then  รายการที่เกี่ยวข้องกับการจ่ายเงินทั้งหมดจะแสดงให้เห็นตามตัวกรองที่เลือก

## Assumptions & Open Questions
- ASM-01 ระบบการเงินเป็นแหล่งข้อมูลสถานะการจ่ายเงิน
- Q-01 ควรแสดงยอดเงินพร้อมสถานะการจ่ายหรือไม่? -> ยืนยันนโยบายข้อมูล
