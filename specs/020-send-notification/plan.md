# Plan: ส่งคำขอแจ้งเตือน (v2)

## วัตถุประสงค์
ปรับปรุงเอกสารข้อกำหนดความต้องการสำหรับระบบส่งคำขอแจ้งเตือนให้มีความชัดเจน สอดคล้อง และพร้อมใช้เป็นฐานสำหรับออกแบบและพัฒนาระบบ โดยเน้นการกำหนดเหตุการณ์ที่ต้องแจ้งเตือน การส่งแบบ asynchronous และการ retry เมื่อส่งไม่สำเร็จ

## ขอบเขตงาน
- ตรวจสอบความชัดเจนของ requirement ในเรื่องเหตุการณ์ที่ต้องแจ้งเตือน
- กำหนดให้ระบบสร้างคำขอแจ้งเตือนที่มีข้อมูลจำเป็นเท่านั้น
- กำหนดหลักการส่งแบบ asynchronous เพื่อไม่ให้ธุรกรรมหลักต้องรอผลการส่ง
- ระบุแนวทาง retry ที่ชัดเจนและมีเงื่อนไขระยะเวลาเพื่อป้องกันการส่งซ้ำเร็วเกินไป
- ตรวจสอบความถูกต้องของ Acceptance Criteria และ Traceability

## แผนการทำงาน
### 1. ปรับความชัดเจนของ requirement
- กำหนดให้ระบบต้องตรวจสอบเหตุการณ์ที่เกิดขึ้นที่ต้องส่งแจ้งเตือน
- ระบุว่า payload ควรมีข้อมูลที่จำเป็นเพียงพอสำหรับระบบแจ้งเตือนในภายหลัง
- แยกความรับผิดชอบของระบบนี้จากขั้นตอนการส่งข้อความจริงให้ผู้ใช้งาน (UC-22)

### 2. ปรับแนวทาง asynchronous delivery
- ระบุให้คำขอแจ้งเตือนส่งแบบ asynchronous และไม่ให้ธุรกรรมหลักรอผลลัพธ์จากระบบแจ้งเตือน
- กำหนดความสัมพันธ์ระหว่างการส่งคำขอกับการบันทึกสถานะรับคำขอ

### 3. ปรับ retry policy
- กำหนด retry สูงสุด 3 ครั้ง
- กำหนดช่วงเวลาในการ retry เป็น 1s, 2s, 4s ตามลำดับ
- ให้มีการบันทึกไว้ในคิวหรือประวัติการส่งสำหรับการ retry ต่อไป

### 4. ตรวจสอบความครบถ้วนของเอกสาร
- Requirement ต้องครอบคลุมเงื่อนไขการสร้างคำขอ การส่งแบบ asynchronous และ retry
- Acceptance Criteria ต้องมีความ measurable และสอดคล้องกับ requirement
- Traceability ต้องชี้ไปยัง requirement และ AC ที่สัมพันธ์กันอย่างถูกต้อง

## ผลลัพธ์ที่คาดหวัง
- เอกสารสเปคมีความชัดเจนและสอดคล้องด้านความต้องการ
- ระบบสามารถส่งคำขอแจ้งเตือนโดยไม่ทำให้ธุรกรรมหลักหยุดชะงัก
- การ retry มีความปลอดภัยและมีเงื่อนไขที่ป้องกันการส่งคำขอซ้ำเร็วเกินไป
- สามารถใช้เป็นฐานสำหรับการออกแบบและพัฒนาระบบในรอบต่อไป

## สถานะปัจจุบัน
- Completed: ปรับ requirement ให้สอดคล้องกับ UC-20
- Completed: ปรับ asynchronous delivery และ retry policy
- Completed: ปรับ Acceptance Criteria ให้ตรงกับ behavior ที่ต้องการ
- Completed: ปรับ Assumption และ Open Question ให้มีความชัดเจนมากขึ้น
- Completed: อัปเดตเอกสารเวอร์ชัน v2 สำหรับ folder นี้
