# Feature: จัดการระบบ
Spec ID: SPEC-17-17- | Source: Use Case Diagram UC-17 | Use case: UC-17
Owner: ทีม A | Status: Draft v1 | Updated: 2569-09-19

## Goal
ผู้ดูแลระบบจัดการข้อมูลตั้งค่าและรายการระบบที่อนุญาตให้ใช้งานภายในระบบ โดยจัดการสิทธิ์การเข้าถึงฟังก์ชัน การกำหนดค่าตั้งค่าสำคัญ และตรวจสอบสถานะบริการ เพื่อให้ระบบทำงานได้ถูกต้อง ปลอดภัย และสามารถตรวจสอบประวัติการเปลี่ยนแปลงได้

## Scope
### In scope
- จัดการผู้ใช้และบทบาทที่ระบบอนุญาต
- จัดการค่าตั้งระบบที่มีผลต่อการทำงานของระบบ
- ตรวจสอบสถานะบริการและการทำงานปัจจุบัน
- บันทึกประวัติการเปลี่ยนแปลงของข้อมูลที่สำคัญ
### Out of scope
- อนุมัติสิทธิ์การเข้าใช้งาน (UC-18)
- การกำหนดนโยบายธุรกิจภายนอกระบบที่ไม่ใช่การตั้งค่าในระบบ

## Constraints
- เฉพาะผู้ดูแลระบบที่ได้รับสิทธิ์เท่านั้นที่สามารถเข้าถึงเมนูและฟังก์ชันจัดการระบบ
- ระบบต้องป้องกันการบันทึกข้อมูลที่ไม่ครบถ้วน ไม่ถูกต้อง หรือซ้ำ
- การเปลี่ยนแปลงที่กระทบความปลอดภัยหรือการทำงานหลักต้องมีการยืนยันและบันทึก audit log
- การตั้งค่าบางรายการที่สำคัญต้องมีการอนุมัติจากผู้ดูแลระดับสูงหรือผู้มีสิทธิ์เพิ่มเติมตามนโยบายของระบบ

## Requirements
- FR-ADM-01 ระบบต้องแสดงเมนูและฟังก์ชันที่ผู้ดูแลมีสิทธิ์เข้าถึงเท่านั้น    <- UC-17 requirement 1
- FR-ADM-02 ระบบต้องตรวจสอบความถูกต้องของข้อมูลก่อนบันทึก เช่น ฟิลด์ที่จำเป็น รูปแบบข้อมูล และค่าที่ไม่ซ้ำ/ไม่ผิดกฎหมาย    <- UC-17 requirement 2
- FR-ADM-03 ระบบต้องบันทึกประวัติการเปลี่ยนแปลงพร้อมข้อมูลผู้ทำรายการ เวลา และรายละเอียดการเปลี่ยนแปลง    <- UC-17 requirement 3

## Quality Requirements
- NFR-SEC-01 ต้องใช้สิทธิ์ระดับผู้ดูแลหรือสูงกว่าในการเข้าถึงการจัดการระบบ
- NFR-AUD-01 ทุกการเปลี่ยนแปลงสำคัญต้องมี audit log ที่สามารถระบุผู้ทำรายการ เวลา และรายละเอียดการเปลี่ยนแปลงได้

## Acceptance Criteria
- [ ] AC-ADM-01 (FR-ADM-01)
      Given ผู้ดูแลระบบ login ด้วยสิทธิ์ที่อนุญาต
            When  เข้าหน้า "จัดการระบบ"
            Then  ระบบแสดงเฉพาะเมนูและฟังก์ชันที่ผู้ดูแลมีสิทธิ์ใช้งาน
- [ ] AC-ADM-02 (FR-ADM-02)
      Given ข้อมูลที่กรอกไม่ครบถ้วนหรือไม่ถูกต้อง
            When  ผู้ดูแลกดบันทึก
            Then  ระบบปฏิเสธการบันทึกและแสดงข้อความแจ้งข้อผิดพลาด
- [ ] AC-ADM-03 (FR-ADM-03)
      Given มีการเปลี่ยนแปลงข้อมูลสำคัญ
            When  บันทึกข้อมูล
            Then  ระบบบันทึกประวัติการเปลี่ยนแปลงพร้อมผู้ทำรายการ เวลา และรายละเอียดการเปลี่ยนแปลง

## Assumptions & Open Questions
- ASM-01 รายการที่ผู้ดูแลแก้ไขได้ถูกกำหนดโดยระบบและขึ้นกับบทบาทของผู้ดูแล
- ASM-02 การอนุมัติแบบสองคนใช้กับค่าตั้งค่าที่มีผลต่อความปลอดภัยหรือสิทธิ์เท่านั้น ส่วนการตั้งค่าอื่น ๆ อนุญาตให้ผู้ดูแลคนเดียวทำการบันทึกได้
- Q-01 การตั้งค่าบางประเภทต้องผ่านการอนุมัติแบบสองคนหรือไม่? -> Clarified: ใช่เฉพาะค่าตั้งค่าที่มีผลต่อความปลอดภัยหรือสิทธิ์ ไม่ใช่ทุกการตั้งค่า
