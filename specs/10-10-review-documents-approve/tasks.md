### T-02: แสดงเอกสารที่ผู้สมัครส่งมาให้พิจารณา
- รองรับ: FR-DOC-01, NFR-SEC-01
- ตรวจด้วย: AC-DOC-03
- ไฟล์ที่แตะ: ไม่มีไฟล์ implementation หรือ test ที่มีอยู่จริงใน repo สำหรับงานนี้
- ต้องทำหลัง: T-01
- เสร็จเมื่อ:
  - แสดงเอกสารของผู้สมัครได้ตามสิทธิ์ที่กำหนดใน FR-DOC-01
  - ปฏิเสธการเข้าถึงเอกสารเมื่อผู้ใช้ไม่มีสิทธิ์ตาม NFR-SEC-01
  - สามารถเปิดดูเอกสารที่จำเป็นสำหรับการตรวจสอบความครบถ้วนและความถูกต้อง
- สถานะ: Pending

### T-03: บันทึกผลการตรวจสอบเอกสารเมื่ออนุมัติ
- รองรับ: FR-DOC-02
- ตรวจด้วย: AC-DOC-01
- ไฟล์ที่แตะ: ไม่มีไฟล์ implementation หรือ test ที่มีอยู่จริงใน repo สำหรับงานนี้
- ต้องทำหลัง: T-01, T-02
- เสร็จเมื่อ:
  - รองรับการบันทึกผลตรวจสอบเมื่อเอกสารถูกต้องครบและอาจารย์อนุมัติ
  - บันทึกผลอนุมัติให้สอดคล้องกับ FR-DOC-02 และ AC-DOC-01
  - ส่งผลการบันทึกกลับเพื่อยืนยันว่าเก็บข้อมูลเรียบร้อยแล้ว
- สถานะ: Pending

### T-04: บังคับให้ระบุเหตุผลเมื่อไม่อนุมัติหรือส่งกลับ
- รองรับ: FR-DOC-03
- ตรวจด้วย: AC-DOC-02
- ไฟล์ที่แตะ: ไม่มีไฟล์ implementation หรือ test ที่มีอยู่จริงใน repo สำหรับงานนี้
- ต้องทำหลัง: T-01, T-02
- เสร็จเมื่อ:
  - รองรับการส่งกลับเอกสารเมื่อเอกสารไม่ถูกต้องตาม FR-DOC-03
  - บังคับให้ระบุเหตุผลก่อนบันทึกผลส่งกลับ/ไม่อนุมัติ
  - ปฏิเสธการบันทึกผลดังกล่าวเมื่อไม่มีเหตุผล ตาม AC-DOC-02
- สถานะ: Pending
