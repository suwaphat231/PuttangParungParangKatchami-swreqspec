# Tasks: ตรวจสอบเอกสารและอนุมัติ (UC-10)

## ภาพรวม
- ฟีเจอร์: ตรวจสอบเอกสารและอนุมัติ
- Use case: UC-10
- ขอบเขต: แสดงเอกสารผู้สมัคร ตรวจสอบความครบถ้วน/ถูกต้อง อนุมัติหรือส่งกลับ
- ข้อกำหนด: FR-DOC-01 ถึง FR-DOC-03, NFR-SEC-01, NFR-AUD-01, AC-DOC-01 ถึง AC-DOC-03
- ไม่รวม: ดูสถานะการสมัครตาม UC-03 และคัดเลือกผู้สมัครตาม UC-08

## รายการงาน

### TASK-01: กำหนดข้อมูลและสิทธิ์การเข้าถึงเอกสารผู้สมัคร
Status: Pending
Owner: Backend / Domain Logic

- ระบุข้อมูลเอกสารของผู้สมัครที่จำเป็นต่อการแสดงและตรวจสอบ โดยประเภทเอกสารที่ต้องใช้ยึดตามประกาศ
- กำหนดการตรวจสิทธิ์ก่อนอนุญาตให้เรียกดูหรือเปิดเอกสาร
- ปฏิเสธการเข้าถึงเอกสารเมื่อผู้ใช้ไม่มีสิทธิ์

Traceability:
- FR-DOC-01
- NFR-SEC-01
- AC-DOC-03

### TASK-02: แสดงเอกสารที่ผู้สมัครส่งมา
Status: Pending
Owner: Backend / Frontend

- แสดงเอกสารของผู้สมัครเพื่อให้อาจารย์ตรวจสอบ
- ให้การเรียกดูเอกสารเป็นไปตามสิทธิ์ที่กำหนด
- แสดงข้อมูลที่จำเป็นสำหรับตรวจสอบความครบถ้วนและความถูกต้อง

Traceability:
- FR-DOC-01
- AC-DOC-03

### TASK-03: บันทึกผลการตรวจสอบเอกสาร
Status: Pending
Owner: Backend / Domain Logic

- รองรับการบันทึกผลตรวจสอบเมื่ออาจารย์อนุมัติเอกสารที่ถูกต้องครบ
- บันทึกผลลัพธ์การตรวจสอบของเอกสาร
- ส่งผลการบันทึกกลับเพื่อยืนยันว่าบันทึกสำเร็จ

Traceability:
- FR-DOC-02
- AC-DOC-01

### TASK-04: บังคับระบุเหตุผลเมื่อส่งกลับหรือไม่อนุมัติ
Status: Pending
Owner: Backend / Frontend

- รองรับการส่งเอกสารกลับเมื่อพบว่าเอกสารไม่ถูกต้อง
- บังคับให้ระบุเหตุผลก่อนบันทึกผลส่งกลับ/ไม่อนุมัติ
- ปฏิเสธการบันทึกผลดังกล่าวเมื่อไม่มีเหตุผล

Traceability:
- FR-DOC-03
- AC-DOC-02

### TASK-05: บันทึกประวัติการตรวจสอบเอกสาร
Status: Pending
Owner: Backend / Data Access

- บันทึกประวัติเมื่อมีการตรวจสอบเอกสาร
- เก็บผลการตรวจสอบและเหตุผลเมื่อมีการส่งกลับหรือไม่อนุมัติ เพื่อให้ประวัติสะท้อนผลการดำเนินการ

Traceability:
- NFR-AUD-01

### TASK-06: ทดสอบการตรวจสอบเอกสารตาม Acceptance Criteria
Status: Pending
Owner: QA

- AC-DOC-01: เอกสารถูกต้องครบและอาจารย์อนุมัติแล้ว ระบบบันทึกผลอนุมัติ
- AC-DOC-02: เอกสารไม่ถูกต้องและส่งกลับ ระบบบังคับให้ระบุเหตุผล
- AC-DOC-03: ผู้ไม่มีสิทธิ์เปิดเอกสารแล้วระบบปฏิเสธการเข้าถึง
- ตรวจสอบว่ามีประวัติการตรวจสอบถูกบันทึกตาม NFR-AUD-01

Traceability:
- AC-DOC-01
- AC-DOC-02
- AC-DOC-03
- NFR-AUD-01
