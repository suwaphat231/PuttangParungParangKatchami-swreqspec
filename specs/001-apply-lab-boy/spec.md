# Feature: สมัครเป็น Lab Boy
Spec ID: SPEC-01-01- | Source: Use Case Diagram UC-01 | Use case: UC-01
Owner: ทีม A | Status: Draft v2 | Updated: 2569-09-19

## Goal
นักศึกษาที่เข้าสู่ระบบแล้วสามารถสมัครเป็น Lab Boy ในประกาศที่เปิดรับสมัคร พร้อมส่งข้อมูลและเอกสารที่เกี่ยวข้อง และได้รับผลการบันทึกการสมัคร

## Scope
### In scope
- แสดงประกาศรับสมัครที่ยังเปิดอยู่
- กรอกข้อมูลและแนบเอกสารสมัคร
- ตรวจสอบคุณสมบัติ/สถานะนักศึกษาก่อนสมัคร
- บันทึกใบสมัครและวันเวลาที่สมัคร
- ถอนใบสมัครก่อนอาจารย์ปิดรับสมัคร
### Out of scope
- การคัดเลือกผู้สมัคร
- การจัดตารางปฏิบัติงาน
- การประเมินการปฏิบัติงาน

## Constraints
- ต้องเข้าสู่ระบบก่อนสมัคร
- ต้องมีประกาศรับสมัครที่อยู่ในช่วงเวลาเปิดรับ
- ข้อมูลที่จำเป็นจากบัญชีผู้ใช้ต้องครบก่อนยืนยัน
- หากสมัครสำเร็จต้องไม่สร้างใบสมัครซ้ำสำหรับประกาศเดียวกัน
- ใช้ข้อมูลจากบัญชีผู้ใช้โดยไม่ต้องแนบเอกสาร
- หากจำนวนผู้สมัครเต็ม ให้รับคำขอตามลำดับเวลาที่ยืนยันสำเร็จ

## Requirements
- FR-LB-01 ระบบต้องแสดงรายละเอียดประกาศและเงื่อนไขการสมัคร    <- UC-01 requirement 1
- FR-LB-02 ระบบต้องตรวจสอบสถานะนักศึกษาก่อนรับใบสมัคร    <- UC-01 requirement 2
- FR-LB-03 ระบบต้องปฏิเสธการสมัครเมื่อข้อมูลหรือเอกสารที่จำเป็นไม่ครบ    <- UC-01 requirement 3
- FR-LB-04 เมื่อยืนยันสำเร็จ ระบบต้องบันทึกใบสมัครพร้อมวันและเวลาที่สมัคร    <- UC-01 requirement 4
- FR-LB-05 หากส่งข้อมูลไม่สำเร็จ ระบบต้องไม่สร้างใบสมัครที่ไม่สมบูรณ์    <- UC-01 requirement 5
- FR-LB-06 นักศึกษาต้องสามารถแก้ไขข้อมูลก่อนยืนยันการสมัคร    <- UC-01 requirement 6
- FR-LB-07 ระบบต้องอนุญาตให้ถอนใบสมัครได้จนกว่าอาจารย์จะปิดรับสมัคร
- FR-LB-08 เมื่อถอนใบสมัครแล้ว การสมัครใหม่ต้องสร้างเลขใบสมัครใหม่
- FR-LB-09 เมื่อระบบทะเบียนตรวจสอบไม่ได้ ระบบต้องสร้างใบสมัครสถานะ `รอตรวจสอบ` และส่งให้อาจารย์ดำเนินการต่อ
- FR-LB-10 เมื่อจำนวนผู้สมัครเต็ม ระบบต้องไม่รับคำขอที่มาถึงภายหลังผู้สมัครที่เต็มจำนวน

## Quality Requirements
- NFR-SEC-01 ข้อมูลการสมัครต้องส่งผ่านช่องทางที่เข้ารหัส
- NFR-REL-01 การบันทึกใบสมัครต้องไม่เกิดรายการซ้ำเมื่อผู้ใช้กดยืนยันซ้ำ
- NFR-USE-01 ขั้นตอนสมัครควรเข้าใจได้และทำสำเร็จโดยไม่ต้องขอความช่วยเหลือ

## Acceptance Criteria
- [ ] AC-LB-01 (FR-LB-04)
      Given ผ่านเงื่อนไขการสมัครและกรอกข้อมูลครบ
            When  ยืนยันการสมัคร
            Then  ระบบบันทึกใบสมัครและแสดงผลสำเร็จ
- [ ] AC-LB-02 (FR-LB-01)
      Given นักศึกษาเลือกประกาศรับสมัคร
            When  เปิดรายละเอียดประกาศ
            Then  ระบบแสดงเงื่อนไข คุณสมบัติ ช่วงเวลารับสมัคร และจำนวนที่รับ
- [ ] AC-LB-03 (FR-LB-02)
      Given นักศึกษาส่งใบสมัคร
            When  ระบบตรวจสอบสถานะนักศึกษา
            Then  นักศึกษาสถานะปกติเท่านั้นจึงสมัครได้
- [ ] AC-LB-04 (FR-LB-03)
      Given ข้อมูลจากบัญชีผู้ใช้ไม่ครบหรือไม่ผ่านเงื่อนไข
            When  ยืนยันการสมัคร
            Then  ระบบปฏิเสธและแสดงข้อมูลที่ต้องแก้ไข
- [ ] AC-LB-05 (FR-LB-05)
      Given การบันทึกข้อมูลล้มเหลว
            When  ยืนยันการสมัคร
            Then  ระบบไม่สร้างใบสมัครที่ไม่สมบูรณ์
- [ ] AC-LB-06 (FR-LB-06)
      Given นักศึกษายังไม่ยืนยันการสมัคร
            When  แก้ไขข้อมูลในฟอร์ม
            Then  ระบบอนุญาตให้แก้ไขข้อมูลก่อนยืนยัน
- [ ] AC-LB-07 (FR-LB-07)
      Given ใบสมัครยังไม่ถูกอาจารย์ปิดรับสมัคร
            When  นักศึกษาถอนใบสมัคร
            Then  ระบบถอนใบสมัครสำเร็จ
- [ ] AC-LB-08 (FR-LB-08)
      Given นักศึกษาถอนใบสมัครเดิมแล้ว
            When  สมัครประกาศเดิมอีกครั้ง
            Then  ระบบสร้างใบสมัครด้วยเลขใบสมัครใหม่
- [ ] AC-LB-09 (FR-LB-09)
      Given ระบบทะเบียนไม่สามารถตรวจสอบสถานะได้
            When  นักศึกษายืนยันการสมัคร
            Then  ระบบสร้างใบสมัครสถานะ `รอตรวจสอบ` และมอบหมายให้อาจารย์ดำเนินการต่อ
- [ ] AC-LB-10 (FR-LB-10)
      Given จำนวนผู้สมัครเต็ม
            When  มีคำขอยืนยันหลายคำขอพร้อมกัน
            Then  ระบบรับเฉพาะคำขอที่ยืนยันสำเร็จตามลำดับเวลาก่อนจนเต็มจำนวน
- [ ] AC-LB-11 (NFR-REL-01)
      Given ผู้ใช้กดยืนยันซ้ำ
            When  ระบบประมวลผลคำขอ
            Then  ต้องมีใบสมัครเพียงรายการเดียว
- [ ] AC-LB-12 (NFR-SEC-01)
      Given นักศึกษาส่งข้อมูลการสมัคร
            When  ระบบรับส่งข้อมูล
            Then  ระบบต้องใช้ช่องทางการสื่อสารที่เข้ารหัส

## Assumptions & Open Questions
- ASM-01 คุณสมบัติผู้สมัครถูกกำหนดไว้ในประกาศรับสมัคร
- ASM-02 ใช้เขตเวลา Asia/Bangkok
- ASM-03 ข้อมูลที่ใช้สมัครดึงจากบัญชีผู้ใช้ และไม่มีเอกสารแนบ
- ASM-04 การถอนใบสมัครทำได้จนถึงเวลาที่อาจารย์ปิดรับสมัคร
- ASM-05 อาจารย์เป็นผู้ดำเนินการใบสมัครสถานะ `รอตรวจสอบ`
- ASM-06 การจัดลำดับผู้สมัครใช้เวลาที่ระบบยืนยันคำขอในเขตเวลา Asia/Bangkok
