## สิ่งที่ยังไม่ทำ
- Q-01 ผู้มีสิทธิ์อนุมัติ (Approver) ต้องมีสถานะที่ชัดเจนในระบบเพื่อให้ระบบสามารถตรวจสอบสิทธิ์อนุมัติได้หรือไม่? -> รอ T-05 (ต้องมีสถานะชัดเจนก่อนเริ่มงานนี้)
- Q-02 ในกรณีที่มีข้อมูลผู้ใช้ผิดพลาด เช่น นักศึกษาเป็นอาจารย์ แต่กำหนดบทบาทหรือสิทธิ์ผิด ต้องให้ Admin หรือผู้ดูแลระบบสามารถแก้ไขให้ถูกต้องได้ทันทีโดยไม่ต้องมีการอนุมัติใหม่หรือไม่? -> แก้ได้เลย; งานนี้รวมอยู่ใน T-06
- Q-03 บัญชีใดต้องอนุมัติด้วยเจ้าหน้าที่อีกคนหรือไม่? -> ตัดสินใจแล้ว: "อนุมัติคนเดียวพอ" สำหรับสิทธิ์ทั่วไป; สำหรับสิทธิ์ความเสี่ยงสูงให้ใช้ Dual Approval (2 คน) เมื่อสิทธิ์ตรงตามกติกา 3 ข้อ: (1) เป็นสิทธิ์ระดับ Admin / System owner, (2) เป็นสิทธิ์เข้าถึงข้อมูลทางการเงินหรือข้อมูลส่วนบุคคล (PDPA), และ (3) เป็นสิทธิ์ที่มีความเสี่ยงต่อการทุจริต (SoD)" ต้องบันทึกเป็นนโยบาย IAM ที่ใช้ในการตรวจสอบก่อนอนุมัติ
- Q-04 มีการแจ้งผลคำขอให้ผู้ยื่นคำขอทราบผ่านอีเมลหรือระบบหรือไม่? -> แจ้งผ่านระบบแจ้งเตือนของระบบเท่านั้น ไม่ต้องยุ่งกับระบบอีเมลภายนอก
