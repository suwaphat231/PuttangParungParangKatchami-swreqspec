# Feature: สมัครเป็น Lab Boy (Application)
Spec ID: SPEC-APP-001 | Source: SRS Requirements ข้อ 1, 2, 5, 6, 7 และ 20 | Use case: UC-01
Owner: ทีมพัฒนาระบบ Lab Boy | Status: Draft v1 | Updated: 2569-09-09

## Goal
นักศึกษาที่เข้าสู่ระบบแล้วสามารถเลือกวิชาปฏิบัติการที่เปิดรับ กรอกข้อมูล และส่งใบสมัครเป็น
Lab Boy ได้ โดยระบบตรวจสอบคุณสมบัติเบื้องต้น บันทึกวัน–เวลาที่สมัครอย่างถูกต้อง และแสดง
หลักฐานยืนยันการรับใบสมัคร เพื่อให้อาจารย์นำข้อมูลไปใช้คัดเลือกและกระจายงานในขั้นตอนถัดไป

## Scope
### In scope
- แสดงรายวิชาปฏิบัติการและกลุ่มเรียนที่เปิดรับ Lab Boy
- แสดงรายละเอียดการรับสมัครและช่วงเวลาที่เปิดรับของแต่ละรายวิชา
- ให้นักศึกษาเลือกรายวิชาและกลุ่มเรียนที่ต้องการสมัคร
- ตรวจสอบสถานภาพนักศึกษาในภาคการศึกษาปัจจุบัน
- ตรวจสอบว่ารายวิชาที่เลือกเป็นวิชาปฏิบัติการ
- แนบและจัดเก็บหลักฐานยืนยันตัวตนหรือสถานภาพนักศึกษา
- บันทึกใบสมัครพร้อมวัน–เวลาจากระบบ และแสดงเลขอ้างอิงใบสมัคร

### Out of scope
- คัดเลือกและจัดลำดับผู้สมัคร (UC-08)
- จัดสรรงานและกระจายโอกาสให้ Lab Boy (UC-08)
- จัดทำตารางปฏิบัติงาน (UC-09)
- บันทึกเวลาปฏิบัติงาน (UC-04)
- คำนวณชั่วโมงและค่าตอบแทน (UC-20)
- เข้าสู่ระบบ (UC-19) — ถือว่าผู้ใช้เข้าสู่ระบบสำเร็จแล้วก่อนเข้าฟีเจอร์นี้ (precondition)

## Constraints
- CON-TECH-01 ระบบต้องใช้ฐานข้อมูล MySQL ตามเทคโนโลยีที่โครงการกำหนด
- DOM-ELG-01 ผู้สมัครต้องมีสถานภาพเป็นนักศึกษาในภาคการศึกษาที่สมัคร
- DOM-COURSE-01 รายวิชาที่เปิดรับ Lab Boy ต้องเป็นวิชาปฏิบัติการ และมีชั่วโมงปฏิบัติการ
  ระบุอยู่ในข้อมูลหน่วยกิต
- DOM-FCFS-01 ระบบต้องใช้วัน–เวลาที่บันทึกจากฝั่งเซิร์ฟเวอร์เป็นหลักฐานลำดับการสมัคร
  สำหรับกระบวนการคัดเลือกแบบ First-come, first-served
- IF-REG-01 ระบบต้องตรวจสอบสถานภาพนักศึกษากับระบบทะเบียนมหาวิทยาลัย หรือใช้หลักฐาน
  ที่หน่วยงานยอมรับในกรณีที่ยังไม่สามารถเชื่อมต่อระบบทะเบียนได้
- CON-TIME-01 การบันทึกและแสดงวัน–เวลาต้องใช้เขตเวลา Asia/Bangkok
- CON-DATA-01 ระบบต้องจัดเก็บชื่อ นามสกุล คำนำหน้าชื่อ และรหัสนักศึกษาอย่างถูกต้อง
  เพื่อใช้จัดทำเอกสารราชการและเอกสารเบิกจ่ายในขั้นตอนถัดไป

## Requirements
- FR-APP-01 ระบบต้องแสดงเฉพาะรายวิชาปฏิบัติการและกลุ่มเรียนที่กำลังเปิดรับ Lab Boy
- FR-APP-02 ระบบต้องแสดงรายละเอียดรายวิชา กลุ่มเรียน จำนวนที่เปิดรับ และช่วงเวลารับสมัคร
  ก่อนที่นักศึกษาจะส่งใบสมัคร
- FR-APP-03 ระบบต้องแสดงชื่อ นามสกุล คำนำหน้าชื่อ และรหัสนักศึกษาของผู้สมัคร
  เพื่อให้ผู้สมัครตรวจสอบก่อนยืนยัน
- FR-APP-04 เมื่อผู้สมัครเลือกรายวิชา ระบบต้องตรวจสอบว่ารายวิชานั้นเป็นวิชาปฏิบัติการ
  หากไม่ผ่านเงื่อนไข ระบบต้องไม่อนุญาตให้ส่งใบสมัคร
- FR-APP-05 เมื่อผู้สมัครยืนยันการสมัคร ระบบต้องตรวจสอบสถานภาพนักศึกษาในภาคการศึกษา
  ปัจจุบันก่อนบันทึกใบสมัคร
- FR-APP-06 ระบบต้องให้ผู้สมัครแนบหลักฐานยืนยันตัวตนหรือสถานภาพนักศึกษาตามรูปแบบ
  และขนาดไฟล์ที่หน่วยงานกำหนด
- FR-APP-07 ระบบต้องปฏิเสธการส่งใบสมัครเมื่อข้อมูลหรือหลักฐานที่จำเป็นไม่ครบถ้วน
  พร้อมระบุรายการที่ต้องแก้ไข
- FR-APP-08 เมื่อข้อมูลผ่านการตรวจสอบ ระบบต้องบันทึกใบสมัครโดยใช้วัน–เวลาจากเซิร์ฟเวอร์
  และสร้างเลขอ้างอิงใบสมัครที่ไม่ซ้ำกัน
- FR-APP-09 เมื่อบันทึกสำเร็จ ระบบต้องแสดงเลขอ้างอิง วัน–เวลาที่สมัคร รายวิชา กลุ่มเรียน
  และสถานะ “รอการพิจารณา”
- FR-APP-10 หากการตรวจสอบสถานภาพกับระบบทะเบียนไม่สำเร็จ ระบบต้องไม่สร้างใบสมัครซ้ำ
  และต้องแจ้งให้ผู้สมัครลองใหม่หรือดำเนินการตามช่องทางสำรองที่กำหนด

## Quality Requirements
- NFR-PERF-01 ระบบต้องแสดงรายการรายวิชาที่เปิดรับและรายละเอียดการสมัครภายใน 3 วินาที
  ในสภาวะการใช้งานปกติ
- NFR-SEC-01 ข้อมูลส่วนบุคคลและหลักฐานของผู้สมัครต้องเข้ารหัสขณะรับส่งด้วย TLS 1.2 ขึ้นไป
- NFR-SEC-02 เฉพาะผู้สมัคร เจ้าของรายวิชา และเจ้าหน้าที่ที่ได้รับสิทธิ์เท่านั้นที่สามารถดู
  ข้อมูลใบสมัครได้
- NFR-AUD-01 ระบบต้องบันทึก audit log เมื่อมีการสร้าง เปิดดู หรือแก้ไขใบสมัคร โดยระบุ
  ผู้ดำเนินการ วัน–เวลา และเลขอ้างอิงใบสมัคร
- NFR-INT-01 เลขอ้างอิงใบสมัครต้องไม่ซ้ำกัน และข้อมูลใบสมัครที่บันทึกสำเร็จต้องไม่สูญหาย
  แม้ผู้ใช้กดส่งซ้ำหรือรีเฟรชหน้าจอ
- NFR-USE-01 หน้าจอสมัครต้องใช้งานได้บนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ
- NFR-AVL-01 ระบบต้องพร้อมให้บริการไม่น้อยกว่า 99% ในช่วงเวลาที่เปิดรับสมัคร
- NFR-BCK-01 ระบบต้องสำรองข้อมูลใบสมัครอย่างน้อยวันละ 1 ครั้ง และสามารถกู้คืนข้อมูลได้

## Acceptance Criteria
- [ ] AC-APP-01 (FR-APP-01, DOM-COURSE-01)
      Given มีทั้งวิชาปฏิบัติการและวิชาบรรยายในภาคการศึกษาปัจจุบัน
      When  นักศึกษาเปิดหน้ารายวิชาที่รับสมัคร
      Then  ระบบแสดงเฉพาะวิชาปฏิบัติการที่อยู่ในช่วงเปิดรับสมัคร
- [ ] AC-APP-02 (FR-APP-03, CON-DATA-01)
      Given นักศึกษาเข้าสู่ระบบและมีข้อมูลประจำตัวในระบบ
      When  เปิดแบบฟอร์มสมัคร
      Then  ระบบแสดงคำนำหน้าชื่อ ชื่อ นามสกุล และรหัสนักศึกษาให้ตรวจสอบก่อนยืนยัน
- [ ] AC-APP-03 (FR-APP-05, DOM-ELG-01)
      Given ผู้สมัครไม่มีสถานภาพเป็นนักศึกษาในภาคการศึกษาปัจจุบัน
      When  กดยืนยันการสมัคร
      Then  ระบบปฏิเสธการสมัคร แสดงเหตุผล และไม่สร้างเลขอ้างอิงใบสมัคร
- [ ] AC-APP-04 (FR-APP-06, FR-APP-07)
      Given ผู้สมัครยังไม่ได้แนบหลักฐานที่กำหนด
      When  กดยืนยันการสมัคร
      Then  ระบบไม่บันทึกใบสมัครและระบุว่าต้องแนบหลักฐานก่อนส่ง
- [ ] AC-APP-05 (FR-APP-08, DOM-FCFS-01, CON-TIME-01)
      Given ข้อมูลผู้สมัครครบถ้วนและผ่านการตรวจสอบคุณสมบัติ
      When  ผู้สมัครยืนยันการสมัคร
      Then  ระบบสร้างใบสมัครหนึ่งรายการ บันทึกเวลาจากเซิร์ฟเวอร์ด้วยเขตเวลา Asia/Bangkok
            และสร้างเลขอ้างอิงที่ไม่ซ้ำกัน
- [ ] AC-APP-06 (FR-APP-09)
      Given ใบสมัครถูกบันทึกสำเร็จ
      When  ระบบแสดงผลการส่งใบสมัคร
      Then  หน้าจอแสดงเลขอ้างอิง วัน–เวลาที่สมัคร รายวิชา กลุ่มเรียน
            และสถานะ “รอการพิจารณา”
- [ ] AC-APP-07 (FR-APP-10, NFR-INT-01)
      Given ระบบทะเบียนไม่ตอบสนอง
      When  ผู้สมัครกดยืนยันหรือกดส่งซ้ำ
      Then  ระบบแจ้งว่าไม่สามารถตรวจสอบสถานภาพได้ ไม่สร้างใบสมัครซ้ำ
            และแสดงช่องทางดำเนินการต่อที่กำหนดไว้
- [ ] AC-APP-08 (NFR-SEC-02, NFR-AUD-01)
      Given ผู้ใช้ที่ไม่มีสิทธิ์พยายามเปิดดูใบสมัครของผู้อื่น
      When  ระบบตรวจสอบสิทธิ์
      Then  ระบบปฏิเสธการเข้าถึงและบันทึกเหตุการณ์ไว้ใน audit log
- [ ] AC-APP-09 (NFR-PERF-01)
      Given ระบบอยู่ในสภาวะการใช้งานปกติ
      When  นักศึกษาเปิดรายการรายวิชาที่รับสมัคร
      Then  ระบบแสดงผลภายใน 3 วินาที

## Assumptions & Open Questions
- ASM-01 อาจารย์หรือเจ้าหน้าที่เป็นผู้กำหนดรายวิชา กลุ่มเรียน จำนวนที่เปิดรับ
  และช่วงเวลารับสมัครไว้ก่อนแล้ว
- ASM-02 ขั้นตอนนี้รับเฉพาะใบสมัคร ส่วนการเรียงลำดับแบบ First-come, first-served
  และการกระจายโอกาสจะดำเนินการใน UC-08
- ASM-03 ผู้สมัครหนึ่งคนสามารถสมัครได้มากกว่าหนึ่งรายวิชา จนกว่าจะมีข้อกำหนดเพิ่มเติม
- ASM-04 ค่าเป้าหมายด้านประสิทธิภาพและ Availability เป็นค่าเสนอเบื้องต้น
  ซึ่งต้องยืนยันกับอาจารย์และฝ่าย IT
- Q-01 นักศึกษาสามารถสมัครซ้ำในรายวิชาและกลุ่มเรียนเดิมได้หรือไม่?
  -> ถามอาจารย์ผู้สอน
- Q-02 หากระบบทะเบียนเชื่อมต่อไม่ได้ สามารถใช้ภาพหน้าจอยืนยันสถานภาพแทนได้ทันทีหรือไม่?
  -> ถามเจ้าหน้าที่ภาควิชา
- Q-03 หลักฐานรองรับไฟล์ประเภทใด ขนาดสูงสุดเท่าใด และต้องเก็บไว้นานกี่ปี?
  -> ถามเจ้าหน้าที่ภาควิชา
- Q-04 ผู้สมัครสามารถแก้ไขหรือถอนใบสมัครก่อนปิดรับได้หรือไม่?
  -> ถามอาจารย์ผู้สอน
- Q-05 รายวิชาหนึ่งเปิดรับ Lab Boy ได้สูงสุดกี่คน และจำนวนแบ่งตามกลุ่มเรียนอย่างไร?
  -> ถามอาจารย์ผู้สอน
