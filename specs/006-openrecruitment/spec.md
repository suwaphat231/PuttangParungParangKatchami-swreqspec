# Feature: เปิดรับสมัคร
Spec ID: SPEC-06-06- | Source: Use Case Diagram UC-06 | Use case: UC-06
Owner: ทีม A | Status: Draft v2 | Updated: 2569-10-02

## Goal
อาจารย์เปิดรอบรับสมัคร Lab Boy พร้อมกำหนดรายละเอียดและช่วงเวลารับสมัคร

## Scope
### In scope
- เลือกวิชา/งานที่รับผิดชอบ
- กำหนดคุณสมบัติ จำนวนที่รับ และช่วงเวลารับสมัคร
- เผยแพร่ประกาศ
### Out of scope
- ดูประกาศรับสมัคร (UC-02)
- สมัครเป็น Lab Boy (UC-01)

## Constraints
- ผู้เปิดรับสมัครต้องเป็นอาจารย์เจ้าของวิชาและมีสิทธิ์ในรายวิชาหรือกิจกรรม
- วันเปิดต้องมาก่อนวันปิด และใช้เขตเวลา `Asia/Bangkok`
- จำนวนที่รับต้องเป็นจำนวนเต็มมากกว่าศูนย์

## Requirements
- FR-REC-01 ระบบต้องให้อาจารย์เจ้าของวิชากำหนดวิชา/งาน คุณสมบัติ จำนวนที่รับ และช่วงเวลารับสมัคร
- FR-REC-02 ระบบต้องตรวจสอบว่าวันเปิดมาก่อนวันปิดและจำนวนที่รับเป็นจำนวนเต็มมากกว่าศูนย์ โดยใช้เขตเวลา `Asia/Bangkok`
- FR-REC-03 เมื่ออาจารย์เจ้าของวิชายืนยันเผยแพร่ข้อมูลที่ถูกต้อง ระบบต้องเปลี่ยนสถานะเป็น `เปิดรับสมัคร`
- FR-REC-04 อาจารย์เจ้าของวิชาต้องแก้ไขรายละเอียดประกาศได้ทั้งขณะเปิดรับสมัครและปิดรับสมัคร โดยไม่สร้างประกาศซ้ำ
- FR-REC-05 ระบบต้องไม่อนุญาตให้เปิดประกาศของวิชาเดิมซ้ำจนกว่าประกาศเดิมจะปิดหรือลบแบบเก็บประวัติ
- FR-REC-06 เมื่อลบประกาศ ระบบต้องเก็บข้อมูลไว้เป็นประวัติและไม่นำไปแสดงเป็นประกาศที่ใช้งานอยู่

## Quality Requirements
- NFR-SEC-01 ตรวจสอบสิทธิ์ของอาจารย์เจ้าของวิชาก่อนสร้าง แก้ไข เผยแพร่ ปิด หรือลบข้อมูลรับสมัคร
- NFR-AUD-01 บันทึกผู้ดำเนินการและเวลาทุกครั้งที่เปิดหรือปิดประกาศ พร้อมเก็บรายละเอียดรอบและรายชื่อผู้สมัครในประวัติ

## Acceptance Criteria
- [ ] AC-REC-01 (FR-REC-03)
      Given กรอกข้อมูลถูกต้อง
            When  ยืนยันเผยแพร่
            Then  ประกาศมีสถานะเปิดรับสมัคร
- [ ] AC-REC-02 (FR-REC-02)
      Given วันปิดก่อนวันเปิด
            When  บันทึก
            Then  ระบบปฏิเสธและแจ้งข้อผิดพลาด
- [ ] AC-REC-03 (FR-REC-02)
      Given จำนวนที่รับเป็นศูนย์ ติดลบ หรือไม่ใช่จำนวนเต็ม
            When  บันทึก
            Then  ระบบปฏิเสธและแจ้งข้อผิดพลาด
- [ ] AC-REC-04 (NFR-SEC-01)
      Given ผู้ใช้ไม่ใช่อาจารย์เจ้าของวิชา
            When  พยายามสร้าง แก้ไข เผยแพร่ ปิด หรือลบประกาศ
            Then  ระบบปฏิเสธการดำเนินการ
- [ ] AC-REC-05 (FR-REC-04)
      Given มีประกาศของอาจารย์เจ้าของวิชาแล้ว
            When  อาจารย์แก้ไขรายละเอียดขณะประกาศเปิดรับสมัครหรือปิดรับสมัคร
            Then  ระบบบันทึกการแก้ไขในประกาศเดิมและไม่สร้างประกาศซ้ำ
- [ ] AC-REC-06 (FR-REC-05)
      Given มีประกาศของวิชาเดิมที่ยังไม่ปิดหรือลบ
            When  ผู้ใช้พยายามเปิดประกาศใหม่ของวิชาเดิม
            Then  ระบบปฏิเสธการเปิดประกาศซ้ำ
- [ ] AC-REC-07 (FR-REC-06)
      Given มีประกาศที่ต้องการลบ
            When  อาจารย์เจ้าของวิชาลบประกาศ
            Then  ระบบเก็บประกาศเป็นประวัติและไม่แสดงในรายการประกาศที่ใช้งานอยู่
- [ ] AC-REC-08 (NFR-AUD-01)
      Given มีการเปิดหรือปิดประกาศ
            When  ระบบบันทึกเหตุการณ์
            Then  ระบบเก็บผู้ดำเนินการ เวลา รายละเอียดรอบ และรายชื่อผู้สมัครของรอบนั้น

## Assumptions & Open Questions
- ASM-01 รายวิชาและผู้รับผิดชอบมีอยู่ในระบบ
- ASM-02 สถานะประกาศมีเพียง `เปิดรับสมัคร` และ `ปิดรับสมัคร` และไม่มีสถานะร่าง
- ASM-03 อาจารย์เจ้าของวิชาแก้ไขรายละเอียดได้ทั้งขณะเปิดรับสมัครและปิดรับสมัคร
- ASM-04 การลบประกาศเป็นการเก็บข้อมูลไว้เป็นประวัติ ไม่ลบถาวร และไม่แสดงเป็นประกาศที่ใช้งานอยู่
- ASM-05 วิชาเดิมเปิดประกาศซ้ำไม่ได้จนกว่าประกาศเดิมจะปิดหรือลบ
