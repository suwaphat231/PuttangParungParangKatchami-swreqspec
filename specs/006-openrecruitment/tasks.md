# Tasks: เปิดรับสมัคร

Feature: เปิดรับสมัคร | Spec ID: SPEC-06-06- | อ้างอิง: plan.md | วันที่: 2569-10-13

สรุป: มี 3 เฟส 4 task, มี 1 task ที่ต้องรอ Open Question, และเฟสแรกที่ลองใช้งานได้จริงคือเฟส 1 การเผยแพร่ประกาศรับสมัคร

## เฟส 1: เผยแพร่ประกาศรับสมัคร (AC-REC-01)

### T-01 เตรียมข้อมูลรายละเอียดการรับสมัครและตรวจสิทธิ์
- รองรับ: FR-REC-01, NFR-SEC-01, Constraint: ผู้เปิดรับสมัครต้องมีสิทธิ์ในรายวิชาหรือกิจกรรม
- ตรวจด้วย: ไม่มี AC ตรง ๆ เป็นงานพื้นฐานของ T-02
- ไฟล์ที่แตะ: ยังไม่ระบุใน plan.md; ต้องกำหนดในแผนทางเทคนิคก่อนเริ่ม implement
- ต้องทำหลัง: ไม่มี
- เสร็จเมื่อ: ระบบรับรายละเอียดวิชา/งาน คุณสมบัติ จำนวนที่รับ และช่วงเวลาจากอาจารย์ที่มีสิทธิ์ได้
- สถานะ: พร้อมทำ

### T-02 ยืนยันการเผยแพร่ประกาศ
- รองรับ: FR-REC-03, NFR-AUD-01
- ตรวจด้วย: AC-REC-01
- ไฟล์ที่แตะ: ยังไม่ระบุใน plan.md; ต้องกำหนดในแผนทางเทคนิคก่อนเริ่ม implement
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: เมื่อยืนยันข้อมูลถูกต้องแล้ว ประกาศมีสถานะเปิดรับสมัครและบันทึกผู้สร้างกับเวลาเผยแพร่
- สถานะ: พร้อมทำ

#### จุดตรวจเฟส 1
- test ที่ต้องผ่านทั้งหมด: `test_AC_REC_01` และ test ของเฟสก่อนหน้าต้องยังผ่าน
- เปิดระบบ: ยังไม่ระบุคำสั่งเปิดระบบใน plan.md
- คนลองเองตาม AC-REC-01:
  Given อาจารย์มีสิทธิ์และกรอกวิชา/งาน คุณสมบัติ จำนวนที่รับ และช่วงเวลาถูกต้อง
  When ยืนยันเผยแพร่
  Then ประกาศมีสถานะเปิดรับสมัคร พร้อมบันทึกผู้สร้างและเวลาเผยแพร่
- ยังขาด: การตัดสินรายละเอียดสิทธิ์แก้ไขหลังเผยแพร่ตาม Q-01

## เฟส 2: ปฏิเสธช่วงเวลารับสมัครไม่ถูกต้อง (AC-REC-02)

### T-03 ตรวจสอบช่วงเวลาและจำนวนที่รับก่อนบันทึก
- รองรับ: FR-REC-02, Constraint: วันเปิดต้องไม่มากกว่าวันปิด
- ตรวจด้วย: AC-REC-02
- ไฟล์ที่แตะ: ยังไม่ระบุใน plan.md; ต้องกำหนดในแผนทางเทคนิคก่อนเริ่ม implement
- ต้องทำหลัง: T-01
- เสร็จเมื่อ: เมื่อวันปิดก่อนวันเปิด ระบบปฏิเสธการบันทึกและแจ้งข้อผิดพลาด โดยไม่สร้างประกาศที่ผ่านการตรวจสอบ
- สถานะ: พร้อมทำ

#### จุดตรวจเฟส 2
- test ที่ต้องผ่านทั้งหมด: `test_AC_REC_01`, `test_AC_REC_02` และ test ของเฟสก่อนหน้าต้องยังผ่าน
- เปิดระบบ: ยังไม่ระบุคำสั่งเปิดระบบใน plan.md
- คนลองเองตาม AC-REC-02:
  Given กรอกวันปิดให้มาก่อนวันเปิด
  When บันทึก
  Then ระบบปฏิเสธและแจ้งข้อผิดพลาด
- ยังขาด: การตัดสินรายละเอียดสิทธิ์แก้ไขหลังเผยแพร่ตาม Q-01
