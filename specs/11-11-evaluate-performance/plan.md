# แผนการดำเนินงาน: ประเมินการปฏิบัติงาน

Spec ID: SPEC-11-11- | Use case: UC-11

## เป้าหมาย
จัดทำความสามารถให้อาจารย์ดูข้อมูลการปฏิบัติงาน กรอกผลตามเกณฑ์ ตรวจสอบข้อมูล และยืนยันผลการประเมินของ Lab Boy โดยบันทึกผู้ประเมิน เวลา และประวัติการเปลี่ยนแปลงอย่างตรวจสอบได้

## ขอบเขต
- อยู่ในขอบเขต: ดูข้อมูลการปฏิบัติงาน กรอกคะแนน/ผลตามเกณฑ์ และยืนยันผลการประเมิน
- ไม่อยู่ในขอบเขต: การส่งผลการปฏิบัติงาน (UC-12) และการติดตาม/ตรวจสอบการจ่ายเงิน (UC-16)

## งานหลัก

### 1. เตรียมข้อมูลแบบประเมิน
- กำหนดโครงสร้างแบบประเมินตามกิจกรรม/รายวิชาและเกณฑ์ที่กำหนดก่อนเปิดรอบ
- แสดงข้อมูลการปฏิบัติงานและรายการประเมินที่เกี่ยวข้อง
- รองรับการระบุคะแนน/ผลตามรายการประเมิน
- อ้างอิง: FR-EVL-01

### 2. ตรวจสอบก่อนยืนยัน
- ตรวจสอบว่าข้อมูลบังคับครบถ้วน
- ตรวจสอบว่าคะแนนอยู่ในช่วงที่กำหนด
- ปฏิเสธการยืนยันเมื่อข้อมูลไม่ถูกต้อง และแจ้งช่วงคะแนนที่ถูกต้อง
- อ้างอิง: FR-EVL-02, AC-EVL-01

### 3. ยืนยันและบันทึกผล
- บันทึกผลการประเมินเมื่อข้อมูลครบและผ่านการตรวจสอบ
- บันทึกผู้ประเมินและเวลาที่ยืนยันผล
- อ้างอิง: FR-EVL-03, AC-EVL-02

### 4. บันทึกประวัติและควบคุมสิทธิ์
- บันทึกประวัติการประเมินและเหตุการณ์ที่เกี่ยวข้องเพื่อการตรวจสอบย้อนหลัง
- จำกัดการแก้ไขผลหลังยืนยันตามบทบาท
- รายละเอียดว่าจะแก้ไขหลังยืนยันได้หรือไม่ และใครเป็นผู้อนุมัติ ต้องยืนยันกับอาจารย์/เจ้าหน้าที่
- อ้างอิง: NFR-AUD-01, NFR-SEC-01, Q-01

## ลำดับการดำเนินงาน
1. ตรวจสอบเกณฑ์การประเมินและข้อมูลกิจกรรม/รายวิชาก่อนเปิดรอบ
2. พัฒนา/ปรับการแสดงข้อมูลและแบบประเมิน
3. พัฒนา validation สำหรับข้อมูลบังคับและช่วงคะแนน
4. พัฒนา workflow การยืนยันและการบันทึกผู้ประเมิน/เวลา
5. เพิ่ม audit history และตรวจสอบสิทธิ์ตามบทบาท
6. ทดสอบตาม acceptance criteria และตรวจสอบ traceability

## เกณฑ์เสร็จสิ้น
- แสดงแบบประเมินตามกิจกรรม/รายวิชาได้ถูกต้อง
- ไม่สามารถยืนยันผลเมื่อคะแนนอยู่นอกช่วงหรือข้อมูลบังคับไม่ครบ
- เมื่อยืนยันสำเร็จ ระบบบันทึกผลพร้อมผู้ประเมินและเวลา
- มีประวัติการประเมินและการควบคุมสิทธิ์ตามข้อกำหนด
- AC-EVL-01 และ AC-EVL-02 ผ่านการทดสอบ
- ไม่กระทบขอบเขตของ UC-12 และ UC-16
