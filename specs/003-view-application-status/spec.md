# Feature: ดูสถานะการสมัคร
Spec ID: SPEC-03-03- | Source: Use Case Diagram UC-03 | Use case: UC-03
Owner: ทีม A | Status: Draft v2 | Updated: 2569-09-19

## Goal
นักศึกษาสามารถตรวจสอบสถานะใบสมัครและผลการดำเนินการล่าสุด

## Scope
### In scope
- แสดงใบสมัครของนักศึกษา
- แสดงสถานะและวันเวลาที่อัปเดตล่าสุด
- แสดงเหตุผลและรายการที่ต้องแก้เมื่อใบสมัครถูกส่งกลับหรือไม่ผ่าน
### Out of scope
- การคัดเลือกผู้สมัคร (UC-08)
- การตรวจสอบเอกสาร (UC-10/UC-14)

## Constraints
- ผู้ใช้ดูได้เฉพาะใบสมัครของตนเอง
- สถานะต้องอ้างอิงจากข้อมูลล่าสุดในระบบ
- ผู้ใช้ต้องเข้าสู่ระบบก่อนดูสถานะ
- รายการใบสมัครเรียงจากรายการที่อัปเดตล่าสุดก่อน และกรองตามประกาศได้

## Requirements
- FR-STS-01 ระบบต้องแสดงรายการใบสมัครของผู้ใช้    <- UC-03 requirement 1
- FR-STS-02 ระบบต้องแสดงสถานะล่าสุดและเวลาที่อัปเดต    <- UC-03 requirement 2
- FR-STS-03 ระบบต้องแสดงเหตุผลเมื่อมีการส่งกลับ/ไม่อนุมัติ    <- UC-03 requirement 3
- FR-STS-04 ระบบต้องรองรับสถานะ `ยื่นแล้ว`, `รอตรวจสอบ`, `ส่งกลับแก้ไข`, `ผ่าน`, `ไม่ผ่าน` และ `ถอนแล้ว`
- FR-STS-05 ระบบต้องแสดงรายการใบสมัครที่เรียงจากการอัปเดตล่าสุดก่อนและกรองตามประกาศได้
- FR-STS-06 ระบบต้องโหลดข้อมูลสถานะล่าสุดเมื่อผู้ใช้เปิดหน้า

## Quality Requirements
- NFR-SEC-01 ผู้ใช้ต้องเข้าถึงเฉพาะข้อมูลใบสมัครของตนเอง
- NFR-REL-01 สถานะต้องไม่ย้อนกลับโดยไม่มีการแก้ไขที่ได้รับอนุญาต
- NFR-USE-01 ผู้ใช้ต้องอ่านสถานะ เหตุผล และรายการที่ต้องแก้ได้เข้าใจง่าย

## Acceptance Criteria
- [ ] AC-STS-01 (FR-STS-01)
      Given ผู้ใช้มีใบสมัครของตนเองหลายรายการ
            When  เปิดหน้าสถานะการสมัคร
            Then  ระบบแสดงรายการใบสมัครของผู้ใช้
- [ ] AC-STS-02 (FR-STS-02)
      Given มีใบสมัคร
            When  เปิดสถานะการสมัคร
            Then  แสดงสถานะล่าสุดและเวลาอัปเดตเป็นเวลา Asia/Bangkok
- [ ] AC-STS-03 (FR-STS-03)
      Given ใบสมัครถูกส่งกลับหรือไม่ผ่าน
            When  ดูรายละเอียด
            Then  แสดงเหตุผลและรายการที่ต้องแก้
- [ ] AC-STS-04 (FR-STS-04)
      Given ใบสมัครมีการเปลี่ยนสถานะ
            When  ผู้ใช้เปิดรายละเอียด
            Then  แสดงเฉพาะสถานะล่าสุดจากชุดสถานะที่กำหนด
- [ ] AC-STS-05 (FR-STS-05)
      Given ผู้ใช้มีใบสมัครหลายรายการ
            When  เปิดหน้าสถานะและเลือกประกาศ
            Then  ระบบเรียงรายการล่าสุดก่อนและแสดงเฉพาะประกาศที่เลือก
- [ ] AC-STS-06 (FR-STS-06)
      Given สถานะใบสมัครถูกอัปเดตในระบบแล้ว
            When  ผู้ใช้เปิดหน้าใหม่
            Then  ระบบแสดงข้อมูลล่าสุดโดยไม่ใช้ข้อมูลเก่าค้าง
- [ ] AC-STS-07 (NFR-SEC-01)
      Given ผู้ใช้มีใบสมัครหลายคน
            When  เปิดหน้าสถานะ
            Then  แสดงเฉพาะข้อมูลของผู้ใช้ปัจจุบัน
- [ ] AC-STS-08 (NFR-REL-01)
      Given ใบสมัครมีสถานะล่าสุดแล้ว
            When  มีการเปลี่ยนสถานะ
            Then  ระบบไม่อนุญาตให้สถานะย้อนกลับโดยไม่มีสิทธิ์
- [ ] AC-STS-09 (NFR-USE-01)
      Given ใบสมัครมีสถานะหรือเหตุผล
            When  ผู้ใช้ดูรายละเอียด
            Then  ข้อมูลต้องแสดงอย่างชัดเจนและเข้าใจได้

## Assumptions & Open Questions
- ASM-01 มีชุดสถานะมาตรฐานที่กำหนดไว้
- ASM-02 ผู้ใช้ต้องเข้าสู่ระบบก่อนเข้าดูสถานะ
- ASM-03 สถานะ `ผ่าน` และ `ไม่ผ่าน` เปลี่ยนโดยอาจารย์เท่านั้น
- ASM-04 ใช้เขตเวลา Asia/Bangkok สำหรับวันเวลาที่อัปเดตล่าสุด
- ASM-05 ระบบโหลดข้อมูลล่าสุดเมื่อเปิดหน้า
