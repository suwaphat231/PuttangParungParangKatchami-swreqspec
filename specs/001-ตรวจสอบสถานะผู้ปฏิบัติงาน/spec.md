# Feature: ตรวจสอบสถานะผู้ปฏิบัติงาน
Spec ID: SPEC-13-13- | Source: Use Case Diagram UC-13 | Use case: UC-13
Owner: ทีม A | Status: Draft v2 | Updated: 2569-09-19

## Goal
เจ้าหน้าที่สามารถตรวจสอบสถานะความคืบหน้าและสถานะปัจจุบันของ Lab Boy ในกระบวนการปฏิบัติงานได้อย่างถูกต้องและทันเวล

## Scope
### In scope
- ค้นหา Lab Boy ตามข้อมูลที่เกี่ยวข้อง
- ดูสถานะการคัดเลือก
- ดูตารางการปฏิบัติงาน
- ดูผลการปฏิบัติงาน
- กรองข้อมูลตามรายวิชาและช่วงเวลา
### Out of scope
- ติดตามและตรวจสอบการจ่ายเงิน (UC-16)

## Constraints
- เจ้าหน้าที่เห็นข้อมูลได้เฉพาะตามสิทธิ์ของภาควิชา
- ข้อมูลสถานะต้องแสดงจากข้อมูลล่าสุดที่อัปเดตเรียบร้อยแล้ว
- ระบบต้องรองรับการค้นหาและการกรองข้อมูลภายในเวลาที่กำหนด

## Requirements
- FR-WKS-01 ระบบต้องแสดงสถานะปัจจุบันของ Lab Boy ในกระบวนการปฏิบัติงาน    <- UC-13 requirement 1
- FR-WKS-02 ระบบต้องรองรับการค้นหาและการกรองข้อมูลตามรายวิชาและช่วงเวลา    <- UC-13 requirement 2
- FR-WKS-03 ระบบต้องแสดงวันและเวลาที่ข้อมูลถูกอัปเดตล่าสุด    <- UC-13 requirement 3

## Quality Requirements
- NFR-SEC-01 จำกัดการเข้าถึงข้อมูลตามสิทธิ์ของภาควิชา
- NFR-PERF-01 การค้นหาและการกรองข้อมูลต้องตอบสนองภายในเวลาที่กำหนด

## Acceptance Criteria
- [ ] AC-WKS-01 (FR-WKS-01)
      Given มีข้อมูล Lab Boy ที่ถูกบันทึกอยู่ในระบบ
            When  เจ้าหน้าที่ค้นหาบุคคลนั้น
            Then  ระบบแสดงสถานะปัจจุบันล่าสุดของ Lab Boy นั้น
- [ ] AC-WKS-02 (FR-WKS-02)
      Given มีข้อมูล Lab Boy หลายคนและมีเงื่อนไขการกรอง
            When  เจ้าหน้าที่กรองตามรายวิชาและช่วงเวลา
            Then  ระบบแสดงเฉพาะ Lab Boy ที่ตรงกับเงื่อนไขที่กำหนด
- [ ] AC-WKS-03 (FR-WKS-03)
      Given ข้อมูล Lab Boy ถูกอัปเดตแล้ว
            When  เจ้าหน้าที่เปิดดูรายละเอียด
            Then  ระบบแสดงวันและเวลาของข้อมูลที่อัปเดตล่าสุด
- [ ] AC-WKS-04 (NFR-SEC-01)
      Given เจ้าหน้าที่มีสิทธิ์เข้าถึงข้อมูลเฉพาะภาควิชาของตน
            When  เข้าดูข้อมูล
            Then  ระบบต้องไม่แสดงข้อมูลที่อยู่นอกสิทธิ์
- [ ] AC-WKS-05 (NFR-PERF-01)
      Given มีจำนวนข้อมูลมากพอ
            When  เจ้าหน้าที่ค้นหาและกรอง
            Then  ระบบต้องตอบสนองภายในเวลาที่กำหนด

## Assumptions & Open Questions
- ASM-01 สถานะมาตรฐานของ Lab Boy จะถูกกำหนดร่วมกันทุกฝ่ายก่อนนำไปใช้จริง
- Q-01 ต้องมีรายงานสรุปสถานะตามช่วงเวลาหรือไม่? -> ยืนยันกับเจ้าหน้าที่
