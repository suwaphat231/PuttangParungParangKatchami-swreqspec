# Feature: คัดเลือกผู้สมัคร
Spec ID: SPEC-08-08- | Source: Use Case Diagram UC-08 | Use case: UC-08
Owner: ทีม A | Status: Draft v2 | Updated: 2569-09-19

## Goal
อาจารย์พิจารณาและบันทึกผลการคัดเลือกผู้สมัคร

## Scope
### In scope
- ดูข้อมูลผู้สมัคร
- กำหนดผลคัดเลือก
- ยืนยันและบันทึกผล
### Out of scope
- จัดทำตารางปฏิบัติงาน (UC-09)
- ดูสถานะการสมัคร (UC-03)

## Constraints
- คัดเลือกได้เฉพาะอาจารย์เจ้าของวิชาในรอบรับสมัครนั้น
- การคัดเลือกจำกัดเฉพาะผู้สมัครที่อยู่ระหว่างการพิจารณา
- อาจารย์สามารถยืนยันผลได้โดยไม่ต้องมีการอนุมัติซ้ำ และไม่จำกัดจำนวนผู้ผ่านตามจำนวนที่รับ

## Requirements
- FR-SEL-01 ระบบต้องให้อาจารย์เจ้าของวิชากำหนดผลคัดเลือกเป็น “ผ่าน” หรือ “ไม่ผ่าน” สำหรับผู้สมัครที่อยู่ระหว่างการพิจารณา    <- UC-08 requirement 1
- FR-SEL-02 ระบบต้องให้อาจารย์เจ้าของวิชายืนยันผลคัดเลือกได้โดยไม่จำกัดจำนวนผู้ผ่านตามจำนวนที่รับ    <- UC-08 requirement 2
- FR-SEL-03 ระบบต้องบันทึกผู้ทำรายการและเวลาที่บันทึกผลคัดเลือก    <- UC-08 requirement 3
- FR-SEL-04 เมื่อยืนยันผลคัดเลือกแล้ว ระบบต้องแจ้งผลให้ผู้สมัครทราบผ่านระบบ

## Quality Requirements
- NFR-AUD-01 ระบบต้องเก็บประวัติการเปิดและปิดรอบรับสมัคร พร้อมรายละเอียดของรอบและรายชื่อผู้สมัครในแต่ละรอบ
- NFR-SEC-01 เฉพาะผู้มีสิทธิ์เท่านั้นที่ยืนยันผลได้

## Acceptance Criteria
- [ ] AC-SEL-01 (FR-SEL-01)
      Given ผู้สมัครอยู่ระหว่างการพิจารณา
            When  อาจารย์เจ้าของวิชากำหนดผลคัดเลือก
            Then  ระบบให้เลือกผลได้เฉพาะ “ผ่าน” หรือ “ไม่ผ่าน”
- [ ] AC-SEL-02 (FR-SEL-02)
      Given มีผู้สมัครมากกว่าจำนวนที่รับ
            When  อาจารย์เจ้าของวิชายืนยันผลคัดเลือก
            Then  ระบบอนุญาตให้ยืนยันได้โดยไม่ตรวจสอบจำนวนผู้ผ่านกับจำนวนที่รับ
- [ ] AC-SEL-03 (FR-SEL-03)
      Given อาจารย์ยืนยันผล
            When  บันทึก
            Then  เก็บผู้ทำรายการและเวลา
- [ ] AC-SEL-04 (FR-SEL-04)
      Given อาจารย์ยืนยันผลคัดเลือก
            When  ระบบบันทึกผลสำเร็จ
            Then  ระบบแจ้งผล “ผ่าน” หรือ “ไม่ผ่าน” ให้ผู้สมัครทราบผ่านระบบ
- [ ] AC-SEL-05 (NFR-SEC-01)
      Given ผู้ใช้งานไม่ใช่อาจารย์เจ้าของวิชา
            When  พยายามยืนยันผลคัดเลือก
            Then  ระบบปฏิเสธการยืนยันผล
- [ ] AC-SEL-06 (NFR-AUD-01)
      Given มีการเปิดหรือปิดรอบรับสมัคร
            When  ระบบบันทึกเหตุการณ์ของรอบ
            Then  ระบบเก็บประวัติการดำเนินการ รายละเอียดของรอบ และรายชื่อผู้สมัครในรอบนั้น

## Assumptions & Open Questions
- ASM-01 จำนวนที่รับกำหนดในประกาศ
- ASM-02 อาจารย์เป็นผู้พิจารณาและเลือกผู้สมัครด้วยตนเอง
- ASM-03 การแก้ไขผลคัดเลือกไม่ต้องบันทึกเป็นประวัติการเปลี่ยนแปลง
