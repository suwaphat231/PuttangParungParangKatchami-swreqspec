# Feature: ตรวจสอบสถานะผู้ปฏิบัติงาน
Spec ID: SPEC-13-13- | Source: Use Case Diagram UC-13 | Use case: UC-13
Owner: ทีม A | Status: Draft v2 | Updated: 2569-09-19

## Goal
เจ้าหน้าที่ตรวจสอบสถานะของ Lab Boy ในกระบวนการปฏิบัติงานตามช่วงเวลา รายวิชา และสิทธิ์การเข้าถึงข้อมูลของภาควิชา

## Scope
### In scope
- ค้นหา Lab Boy ด้วยรหัสนักศึกษา หรือชื่อ-นามสกุล
- ดูสถานะปัจจุบันของ Lab Boy ตามสถานะมาตรฐาน: คัดเลือกแล้ว / กำลังปฏิบัติงาน / ปฏิบัติงานเสร็จสิ้น / ยกเลิก/พ้นสภาพ
- กรองข้อมูลตามภาคการศึกษา ปีการศึกษา รายวิชา ช่วงเวลาปฏิบัติงาน และสถานะ
- แสดงวันและเวลาที่ข้อมูลถูกอัปเดตล่าสุด
### Out of scope
- ติดตามและตรวจสอบการจ่ายเงิน (UC-16)

## Constraints
- เจ้าหน้าที่ภาควิชาเห็นข้อมูล Lab Boy เฉพาะรายวิชาที่สังกัดภาควิชาตนเอง
- อาจารย์ผู้สอนเห็นเฉพาะ Lab Boy ในรายวิชาที่ตนเองรับผิดชอบ
- ผู้ดูแลระบบเห็นข้อมูลทุกภาควิชาและสามารถสลับภาควิชาที่ต้องการดู
- สถานะต้องมาจากข้อมูลล่าสุด และแสดง timestamp หลักที่ถูกอัปเดต

## Requirements
- FR-WKS-01 ระบบต้องแสดงสถานะปัจจุบันของ Lab Boy ตามสถานะมาตรฐานที่กำหนด (`คัดเลือกแล้ว`, `กำลังปฏิบัติงาน`, `ปฏิบัติงานเสร็จสิ้น`, `ยกเลิก/พ้นสภาพ`) <- UC-13 requirement 1
- FR-WKS-02 ระบบต้องค้นหาและกรองข้อมูล Lab Boy ได้ตามรหัสนักศึกษา, ชื่อ-นามสกุล, รายวิชา, ภาคการศึกษา, ช่วงเวลาปฏิบัติงาน และสถานะ หากไม่พบข้อมูลให้แสดงข้อความ "ไม่พบข้อมูลผู้ปฏิบัติงานตามเงื่อนไขที่ระบุ" <- UC-13 requirement 2
- FR-WKS-03 ระบบต้องแสดงวันและเวลาที่ข้อมูลถูกอัปเดตล่าสุด (Last Updated Timestamp) ในหน้าจอรายละเอียดของ Lab Boy <- UC-13 requirement 3

## Quality Requirements
- NFR-SEC-01 จำกัดข้อมูลตามสิทธิ์และบทบาทของผู้ใช้งาน
- NFR-PERF-01 การค้นหาและการกรองต้องตอบสนองภายในเวลาที่กำหนด

## Acceptance Criteria
- [ ] AC-WKS-01 (FR-WKS-01)
      Given มีข้อมูล Lab Boy ในระบบ
            When  เจ้าหน้าที่เปิดดูรายการสถานะ
            Then  ระบบแสดงสถานะล่าสุด (`คัดเลือกแล้ว`, `กำลังปฏิบัติงาน`, `ปฏิบัติงานเสร็จสิ้น`, `ยกเลิก/พ้นสภาพ`) ของ Lab Boy แต่ละคนตามสิทธิ์ภาควิชา
- [ ] AC-WKS-02 (FR-WKS-02)
      Given เจ้าหน้าที่ต้องการค้นหาหรือจำกัดขอบเขตข้อมูล
            When  ระบุรหัสนักศึกษา, เลือกรายวิชา, ภาคการศึกษา หรือช่วงเวลาปฏิบัติงาน
            Then  ระบบแสดงเฉพาะรายการที่ตรงเงื่อนไข หากไม่พบข้อมูลให้แสดงข้อความแจ้งเตือน "ไม่พบข้อมูลผู้ปฏิบัติงานตามเงื่อนไขที่ระบุ"
- [ ] AC-WKS-03 (FR-WKS-03)
      Given ข้อมูลสถานะหรือตารางงานมีการเปลี่ยนแปลง
            When  เจ้าหน้าที่เปิดดูรายละเอียดผู้ปฏิบัติงาน
            Then  ระบบแสดงวันและเวลาที่ข้อมูลถูกอัปเดตล่าสุด (`Last Updated Timestamp`) ในหน้าจอ

## Assumptions & Open Questions
- ASM-01 สถานะมาตรฐานถูกกำหนดร่วมกันทุกฝ่าย
- ASM-02 การเปลี่ยนสถานะเป็นอัตโนมัติเมื่อถึงวันเริ่มงานหรือสิ้นสุดงาน และเปลี่ยนด้วยเจ้าหน้าที่เมื่อมีการยกเลิก/พ้นสภาพ
- Q-01 ต้องมีรายงานสรุปสถานะตามช่วงเวลาหรือไม่? -> ยืนยันกับเจ้าหน้าที่
