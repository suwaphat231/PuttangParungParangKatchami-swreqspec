# Implementation Plan: UC-13 ตรวจสอบสถานะผู้ปฏิบัติงาน
Spec Target: [specs/13-13-check-worker-status/spec.md](specs/13-13-check-worker-status/spec.md) (v2)

## 1. การรองรับเงื่อนไขใน Spec (Constraints & Scope)
- **การจำกัดสิทธิ์ (NFR-SEC-01):** กรองข้อมูล Lab Boy ตามภาควิชาและบทบาทผู้ใช้ (เจ้าหน้าที่ภาควิชา / อาจารย์ / Admin)
- **ข้อมูลและสถานะล่าสุด (FR-WKS-01, FR-WKS-03):** ดึงสถานะปัจจุบันพร้อมวันเวลาอัปเดตล่าสุด (Last Updated Timestamp)

## 2. ขั้นตอนการพัฒนา (Implementation Tasks)
- [ ] **ส่วนประมวลผลข้อมูล (Backend):**
  - สร้างระบบดึงข้อมูลและกรองตาม รหัสนักศึกษา, ชื่อ-นามสกุล, รายวิชา, ภาคการศึกษา และสถานะ
  - ตรวจสอบสิทธิ์การเข้าถึงข้อมูลรายวิชาตามภาควิชาของผู้ใช้งาน
- [ ] **ส่วนหน้าจอผู้ใช้งาน (Frontend):**
  - ทำช่องค้นหาและตัวกรองข้อมูล
  - ตารางแสดงรายการ Lab Boy และสถานะมาตรฐาน (`คัดเลือกแล้ว`, `กำลังปฏิบัติงาน`, `ปฏิบัติงานเสร็จสิ้น`, `ยกเลิก/พ้นสภาพ`)
  - แสดงข้อความแจ้งเตือน "ไม่พบข้อมูลผู้ปฏิบัติงานตามเงื่อนไขที่ระบุ" กรณีค้นหาไม่พบข้อมูล (FR-WKS-02)
  - แสดงเวลาที่อัปเดตล่าสุดในหน้าจอ

## 3. รายการตรวจสอบ (Acceptance Criteria Checklist)
- [ ] **AC-WKS-01:** แสดงสถานะถูกต้องตามสิทธิ์ภาควิชา
- [ ] **AC-WKS-02:** ค้นหาและกรองข้อมูลได้ พร้อมแสดงข้อความเมื่อไม่พบข้อมูล
- [ ] **AC-WKS-03:** แสดงวันและเวลาอัปเดตล่าสุดถูกต้อง

## 4. วัตถุประสงค์ของแผน
